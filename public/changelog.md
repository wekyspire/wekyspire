- 新卡：铁雨、高速魏启罐 / 高速大魏启罐、HeLiCoPtEr（把手牌变成 0 费猛烈肘击）、爆燃 / 焚烧 / 焚天 / 星炎、鬼火；练刀重做为 D/C/B 链

### 改进
- **切幕器与对话播放器拆成两层**：切幕开始 → 目的地就位 → 切幕结束（切到对话不再「黑幕播完才蹦出来」）；cutscene 进出塔楼同样走切幕
- 战斗 → 战后奖励 → 塔楼的节拍调整：战斗结束**先开奖励（不切幕）**，领取 / 跳过后才切幕回塔楼并播楼层 clear 动画
- UI 风格扁平化：白字淡蓝按钮、去掉自体发光与金色大字（金色只留金钱相关内容）、对话框改黑色半透明 flat 框
- 训练可以不做：训练面板去掉「跳过」键（直接离开即可），营地休整保留一次性提示
- 卡牌调整：养刀术 +2 → +3；锻刀术改为「所有刀法牌」+1
