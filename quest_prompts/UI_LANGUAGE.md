# UI 设计语言（2026-10-11 定稿起笔，同日扩充字体/质感/涂鸦章）

> 玩家可见的一切 UI 铬件（按钮/面板/条/槽/角标/对话框/tooltip）遵循本文。
> 卡牌卡面、单位立绘、场景道具、资源水晶/金币、单位状态条等**游戏内容视觉**不属
> UI 铬件，不受本文约束——例外：**字体章管到卡牌文本**（用户 2026-10-11 定）。
> 本文只管 UI 与文本风格；游戏美术主体语言（lowpoly + 厚涂涂鸦）另成一系，
> 不由《加载界面》概念图（`art_src/UI风格概念/加载界面.png`）代表。

## 形状语言：方角 + 厚边框

- 一切 UI 铬件 **0 圆角**（方角）。旧「圆角 + 细描边」语言已废弃——目标是踏实、
  不纤弱。
- 边框一律**厚描边**：3D 烘焙 ≈ 3 逻辑 px（10px/wu 口径，约短边 5%）；DOM/CSS 2px。
  不再有 1px 级细边。
- 配色 = **黑白主题**（2026-10-11 用户定）：底 = 近黑中性灰，边框/文字 = 白与灰阶。
  **语义色白名单**（同日扩充）：稀有度、灵脉与卡牌主题色、敌人红、血条红绿、
  伤害文本、卡牌装饰、效果与 named 名词——语义色只出现在内容物上，
  UI 框架无彩。金色只留给金钱相关内容；标题白 `#f2f2f2` / 提示灰 `#c2c2c2`。
- 交互反馈：一般按钮以**压暗**为反馈（不引入彩色）；特别按钮（关键确认等）
  可加**橙色**强调。

## 字体：黑体骨架（2026-10-11 用户定）

- 字族（双字族，2026-10-11 用户定）：**标题/数字/短语 = 文道潮黑**（展示字族，
  免费商用）；**成句/成段正文 = 思源黑体 TC Bold**（SIL OFL 免费商用）——
  潮黑成段太挤，正文辨识度优先。两族都只发行单字重，**全线禁止叠 bold**
  （合成加粗膨胀笔画、字挤成团）；层级靠字号与 8° 倾斜区分，不靠字重。
- 两级口径：**标题 = 黑粗体**（沿用概念图签名：粗重、带前倾动势——中文无真斜体，
  倾斜由烘焙层/CSS 合成约 8° 实现）；**正文 = 黑体直立**。卡牌卡面文本同此口径。
- 描边纪律：**发丝级**（fontPx×0.07、下限 1.2 逻辑 px）且**与粗体互斥**——
  字重本体已足量，厚描边只降辨识度；描边不再承担「仿粗」职责。
- 落地口径：字体子集化 woff2（构建期扫描全库静态文本取字形集），随资源加载链
  下发；DOM 走 `@font-face`，canvas 烘焙走同一 FontFace（`document.fonts.ready`
  之后烘焙，防止系统字体抢烘）。

## 粗粝质感：程序化纹理平铺（2026-10-11 用户定）

- 粗粝感来源 = 一张 **256×256 程序化生成纹理**（canvas 噪声 + 干笔刷笔触，
  运行期生成一次，零美术资产）。
- 用法：需要**实心填充**的铬件（进度条边框、进度条内容、按钮填充等）直接
  **repeat 平铺**此纹理——3D 烘焙件用 CanvasTexture（wrapS/T = Repeat），
  DOM 侧用 `background-image`。描边线条不挂质感。

## 加载涂鸦：瑞米序列帧（2026-10-11 用户定）

- 概念图右下角的白描小兽（瑞米）是**通用加载动画**：sprite 序列帧，出现于
  加载界面与幕间切幕黑屏的右下角。白描线稿、低存在感、只占非交互角落。
- 素材管线：Seedance 生成瑞米行走视频 → `tools/buildRemiSprite.py` 抽循环段
  切 12 帧条带（`public/ui/remi_loader.png`）；加载壳与幕间层 CSS `steps(12)` 播放。

## 例外类目

- **icon 类按钮 = 无底无框**：纯以带 alpha 的图标表示（首例 = 顶栏卡组按钮，
  `assets/ui/deck_chip`）。hover 只做缩放反馈，命名靠 tooltip；信息性角标
  （张数等）保留，角标自身方角厚边。
- **有美术素材的展示物直出素材**：遗物等已有立绘的展示位**不画底片、不画边框**，
  立绘直接呈现；素材缺席才回落「方角厚描边底片 + 特征字」占位（稀有度色描边）。
