# ENEMY_FX — 敌人演出逐个精工台

> 2026-10-16 用户裁决：10-15 演出批整体未过质量线（电弧通过，其余大多廉价，
> 部分需完全重做）。本文档是重做工作台：**一次一个动作**——构思 → 写设计稿 →
> 实现 → 验收 → 状态归档。禁止一次设计多个（每个都会烂）。

## 质量基线（通过案 = pyro 重击、静电链）

四要素缺一不可：

1. **shader 形体主体**：动作的核心视觉是有内部结构的形体（分层亮度、行进波、
   瓣化、边缘熄灭），不是一张贴图尺度的纸，也不是离散粒子凑数。色参常量 vec3
   烘进 Fn；Fn ≤4 参。
2. **材料真实的运动**：形体按材料真相动——电 = 离散跳变（jolt 重掷）；胶 = 粘弹
   拉伸与断裂；岩 = 惯量与碎屑。缩放渐隐不是运动。
3. **双层粒子**：快层（细、疾、短命）+ 慢层（大、缓、长命）配主形体。
4. **借池灯 punch + 姿态叙事**：light:fxN 只推参数；姿态有蓄-放-收节拍，出口归中。

每个动作先回答：**这个动作的材料是什么、叙事分几拍、玩家该读出什么**。

**频度与元素预算（2026-10-16 用户定，史莱姆首版翻车教训）**：动作的演出量
与它的出场频度成反比。高频基础攻击（每两回合必见）——到命中 ≤400ms、
同时在场元素 ≤3、一拍读懂；四要素满配（形体+双层粒子+灯+姿态全开）只留给
签名动作与重击时刻。元素堆叠 = 过度设计，不如老版干脆的节奏骨架。

**高度感知定位（2026-10-16 用户裁定）**：`unit.position` = 立牌**脚下**中心，不是
身体中心；一切「身体高度」锚（胸/头/口/受击中弹位）按 `unitH = _standeeHeight ×
_baseScale` 比例取（胸 0.52H / 头 0.92H / 中弹 0.50H / 口 0.38H / 脚 0.05H，助手
`fxPieces.unitH`）——固定偏移（旧 3.4/4.9×s 从血条基准抄来）只对平均体型成立，
大个子会锚到胫骨、特效看起来「全定在基座」。

**粒子物理动机（2026-10-16 用户裁定，绿色粒子投诉）**：粒子必须有物理动机与
叙事位——溅点、坠落点、冲击点、飞行尾迹。「在单位基座中心喷两坨色点」不表达
任何东西（诡异且无意义），是噪音不是反馈。双层粒子的本意是**形体的陪衬层**，
不是每拍必撒的装饰；纯姿态/纯液化能讲清的动作就不配粒子。

## 工作法

1. 按出场率 × 签名度选出下一个动作，在本文写完整设计稿（叙事、节拍表、形体
   规格、粒子、灯、姿态、验收点）。
2. 实现 → node 冒烟 → fxGallery 连拍 → 真战斗探针 → 4.5v 结构核对
   （参考帧 `tmp/play/enemyfx/`：pyroheavy-03 基准、电弧通过帧）。
3. 不通过就打磨重验；归档状态后才开始下一个。

受击主题（命中瞬间的种族附加件）与复苏 garnish **随所属敌人的迭代一并重做**，
不单独排队。

**设计总纲：能量方向二分。**
- **爆怒** = 内压外溢：血气上头、轮廓升温、末拍憋不住炸开一圈。
- **聚能** = 环境内汇：光带与尘被抽向胸口焦点，焦点增亮到临界一闪。
- 余下三家按**身体机制**分派（不是能量语义，不发光球）：竖刺=边光上爬、
  硬化=壳锁伏低、掘洞恢复=扬尘下沉。

### A 爆怒 rageSwell ≈ 640ms（youngRakshasa 力量2；低频签名档，四要素满配）
