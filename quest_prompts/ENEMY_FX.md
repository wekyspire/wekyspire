> 2026-10-16 用户裁决：10-15 演出批整体未过质量线（电弧通过，其余大多廉价，
> 部分需完全重做）。本文档是重做工作台：**一次一个动作**——构思 → 写设计稿 →
> 实现 → 验收 → 状态归档。禁止一次设计多个（每个都会烂）。

## 质量基线（通过案 = pyro 重击、静电链）

四要素缺一不可：

1. **shader 形体主体**：动作的核心视觉是有内部结构的形体（分层亮度、行进波、
   瓣化、边缘熄灭），不是一张贴图尺度的纸，也不是离散粒子凑数。色参常量 vec3
   烘进 Fn；Fn ≤4 参。
2. **材料真实的运动**：形体按材料真相动——电 = 离散跳变（jolt 重掷）；胶 = 粘弹
   拉伸与断裂；岩 = 惯量与碎屑。缩放渐隐不是运动。
3. **双层粒子**：快层（细、疾、短命）+ 慢层（大、缓、长命）配主形体。
4. **借池灯 punch + 姿态叙事**：light:fxN 只推参数；姿态有蓄-放-收节拍，出口归中。

每个动作先回答：**这个动作的材料是什么、叙事分几拍、玩家该读出什么**。

## 工作法

1. 按出场率 × 签名度选出下一个动作，在本文写完整设计稿（叙事、节拍表、形体
   规格、粒子、灯、姿态、验收点）。
2. 实现 → node 冒烟 → fxGallery 连拍 → 真战斗探针 → 4.5v 结构核对
   （参考帧 `tmp/play/enemyfx/`：pyroheavy-03 基准、电弧通过帧）。
3. 不通过就打磨重验；归档状态后才开始下一个。

受击主题（命中瞬间的种族附加件）与复苏 garnish **随所属敌人的迭代一并重做**，
不单独排队。

## 迭代 #1：史莱姆·弹性打击（gel strike）

**状态**：✅ 结构验收通过（2026-10-16，4.5v 逐帧核对 + 真战斗锚定连拍）。
**开放项**：胶色系待拍板——史莱姆立绘是纯灰度（色彩全靠场景灯光染，火把暖光
下渲成暖红棕），绿 goo 与暖棕本体并存目前读感和谐（4.5v 判定），但若后续给史莱姆
上彩，goo 色系跟随重调。

**范围**：slime / slimeB / slimeletA / slimeletB 的**攻击动作全套**——起手拍、
突进覆写、命中主题。防拍（护盾/蓄势）与死亡（融化）留各自后续迭代。

**材料真相**：粘弹性流体。压缩蓄能、表面张力、脉冲后果冻共振、带尾液滴、湿溅。
史莱姆攻击不是「动物扑咬」，是**一团胶把自己弹射出去**。

**叙事四拍**：蓄压（体积压缩、渗胶成池）→ 弹射（跳弧拉伸、胶丝拉断）→
胶冠（命中液溅）→ 果冻回巢（衰减振荡）。

### A 起手拍「蓄压」 enemyAct ≈ 560ms

| 时段 | 姿态（_pose） | 形体/粒子/灯 |
|---|---|---|
| 0–250ms | squash 1→0.58、widen 1→1.36（power2.in，被压下去） | gooPool uProg 0→0.75（压力池随压缩涨）；池灯 fx0 绿 0→340 缓升 |
| 250–420ms | 保持 + 颤振渐强（9Hz，幅 0.012→0.032，squash/widen 反相）+ 末段再压一格（→0.55） | 池涨满 uProg 1.0；t≈300/380 体侧各 2 颗慢坠胶珠（gravity 滴落） |
| 420–560ms | 颤振渐弱（能量收回） | gooPool uProg→0（渗胶收回体内，150ms）；灯随收 |

出口状态：深压缩（squash≈0.55）静止一瞬，交棒突进。

### B 突进「弹射→回巢」 lunge override ≈ 170ms + 350ms

新钩子 `registerEnemyLunge(defId, {approach, recover})`（同通用突进契约：
approach 命中前 await 演完，recover 返回 promise 与受击并行，onKill 归位归零）。

- **approach 170ms**：弧线跳（y = sy + sin(πt)·2.2，行程 = reach）；squash
  0.55→1.46（power3.out 拉伸，飞行姿态是「拉长的胶」）；lean 随方向至 1.2×。
  - **gooStrand 胶丝**：池位→身体实时跟随（onUpdate 重摆 midpoint/rotation/
    scale.y=dist）；中段随拉伸掐细，t≈0.62 时断裂（中段熄灭、残珠下坠、整丝淡出）。
  - 断裂时刻甩脱双层胶珠：快层 8 颗（疾、小）+ 慢层 4 颗（缓、大、长命）。
- **recover 350ms**：反弹小弧回巢 130ms（squash 1.46→0.74，落地压扁）→
  果冻振荡 220ms（squash 0.74→1 基线 + 0.22·sin 衰减，widen 反相）。

### 形体件规格（fxPieces.js）

**gooPoolShade(vUv, uProg, uTime, uSeed)** 贴地平躺 quad：
- 半径 R = 0.20 + 0.30·uProg；角向 fbm 边缘（3 频 sin：3/5/8 环波，慢漂）。
- 体色深绿 (0.05,0.16,0.06) ×（1 + 焦散×2.4）；焦散 = 双层异频流动条纹平方
  ×径向衰减。
- 亮缘：外沿窄亮线（深绿亮 (0.28,0.85,0.30)×1.6，呼吸微闪）。
- 微泡×3：笛卡尔位慢轨道漂移，fract 相位上升、到顶增亮后消。
- 收回 = uProg 回落（半径缩 + 亮度随 uProg 缩），边缘熄灭 mask。

**gooStrandShade(vUv, uProg, uSnap, uColor)** 竖直 quad（宽 2.6、height 1、
scale.y=dist 实时摆）：
- 双细丝 x=±0.18，厚 0.055·(1 − pinch·sin(πv))，pinch = clamp(uProg·1.4)。
- 丝体 uColor + 白绿热核（窄高斯）；v = 0 池端锚粗、1 身端。
- uSnap 0→1（130ms）：中段 v≈0.48±(0.10+0.25·uSnap) 渐宽熄灭；残珠
  v 0.48→0.23 下坠缩径；整丝亮度 (1−uSnap)^0.7。

**gooCrownShade(vUv, uProg, uColor, uSeed)** 竖直 billboard（≈12×9）：
- 6 瓣静态展开：方向 (sin Aᵢ, cos Aᵢ)，Aᵢ = (i−2.5)·0.55 + 0.15·sin(uSeed+i)。
- 瓣心行程 0.18 + uProg·(0.55 + 0.18·sin(uSeed·3.7+i·1.3))；blob 随程变宽
  （mix(240,90,uProg) 高斯），头部窄亮核 ×1.8，整体 (1−uProg)^1.2 淡出。
- 底部溅幕：中心下位椭圆 ×(1−uProg)²；热核闪：前 30% exp(−r²·90)×2.2 白绿。
- 边缘熄灭 mask。
