## 质量基线（通过案 = pyro 重击、静电链）

四要素缺一不可：

1. **shader 形体主体**：动作的核心视觉是有内部结构的形体（分层亮度、行进波、
   瓣化、边缘熄灭），不是一张贴图尺度的纸，也不是离散粒子凑数。色参常量 vec3
   烘进 Fn；Fn ≤4 参。
2. **材料真实的运动**：形体按材料真相动——电 = 离散跳变（jolt 重掷）；胶 = 粘弹
   拉伸与断裂；岩 = 惯量与碎屑。缩放渐隐不是运动。
3. **双层粒子**：快层（细、疾、短命）+ 慢层（大、缓、长命）配主形体。
4. **借池灯 punch + 姿态叙事**：light:fxN 只推参数；姿态有蓄-放-收节拍，出口归中。

每个动作先回答：**这个动作的材料是什么、叙事分几拍、玩家该读出什么**。

**频度与元素预算（2026-10-16 用户定，史莱姆首版翻车教训）**：动作的演出量
与它的出场频度成反比。高频基础攻击（每两回合必见）——到命中 ≤400ms、
同时在场元素 ≤3、一拍读懂；四要素满配（形体+双层粒子+灯+姿态全开）只留给
签名动作与重击时刻。元素堆叠 = 过度设计，不如老版干脆的节奏骨架。

**高度感知定位（2026-10-16 用户裁定）**：`unit.position` = 立牌**脚下**中心，不是
身体中心；一切「身体高度」锚（胸/头/口/受击中弹位）按 `unitH = _standeeHeight ×
_baseScale` 比例取（胸 0.52H / 头 0.92H / 中弹 0.50H / 口 0.38H / 脚 0.05H，助手
`fxPieces.unitH`）——固定偏移（旧 3.4/4.9×s 从血条基准抄来）只对平均体型成立，
大个子会锚到胫骨、特效看起来「全定在基座」。

**粒子物理动机（2026-10-16 用户裁定，绿色粒子投诉）**：粒子必须有物理动机与
叙事位——溅点、坠落点、冲击点、飞行尾迹。「在单位基座中心喷两坨色点」不表达
任何东西（诡异且无意义），是噪音不是反馈。双层粒子的本意是**形体的陪衬层**，
不是每拍必撒的装饰；纯姿态/纯液化能讲清的动作就不配粒子。

## 工作法

1. 按出场率 × 签名度选出下一个动作，在本文写完整设计稿（叙事、节拍表、形体
   规格、粒子、灯、姿态、验收点）。
2. 实现 → node 冒烟 → fxGallery 连拍 → 真战斗探针 → 4.5v 结构核对
   （参考帧 `tmp/play/enemyfx/`：pyroheavy-03 基准、电弧通过帧）。
3. 不通过就打磨重验；归档状态后才开始下一个。

受击主题（命中瞬间的种族附加件）与复苏 garnish **随所属敌人的迭代一并重做**，
不单独排队。

**环纪律（2026-10-17 用户定）**：环 = 全向广播语义专用（嚎叫/气压/威慑宣示）；
**攻击性声波禁用环**——无指向性、像施法——攻击性声波走定向波前模板（朝目标的
锥形行进波包；现无消费者，立规防误用）。

**粒子纪律（2026-10-17 用户定，「粒子成了水桶」）**：粒子不是每拍的标配配料。
没有物理动机（溅落 / 冲击 / 拖尾 / 挤出 / 甩脱——动作在物质世界里碰到了什么）
就不许有粒子；**「单点全向爆一撮圆点、只换颜色」是禁用模式**——除颜色外
无形态差异的粒子等于没有设计。体态拍默认纯体态。

- **雷条带 `boltShade`**（TSL，Fn 5 参）：白热核 `vec3(3.0,3.7,5.6)` 乘算推过
  bloom 阈 1.45，电晕 `vec3(0.34,0.80,2.30)`；第二细股、端点亮斑、**激发窗**
  （前沿画未激发段、后沿消隐已激发段）、**流动时序**（每段折线独立闪烁相位 +
  沿弧行进的窄电流前锋）、端部纵向软尾；颜色烘常量（不挂 Color uniform）。
- **首尾粗细包络（uSeed 打包 leaf/end/tip，uState.w = 波形幅度）**：着色距离除以
  `pow(sin(πv),leaf) × (1 − v·end)`——leaf 让中段鼓、两端收细（爪痕柳叶形），
  end 让靶端细于源端（放电锥形），内核/电晕/帷幕同步收。端点亮斑贴**真端点**
  （面片两端各外扩 6%，真端点在 uv ±0.446；画在 ±0.5 会被边缘熄灭裁成半只、
  并浮在锚点外侧一截）。
- **33 行折线条带**（`setBoltQuad`，名字沿用）：折线**烘进几何**（中点位移生成
  大折→碎折，世界尺度摆幅 ±(6–13)% 弧长，不受光晕宽度限制），截面轴 = 局部航线 ×
  视向；局部横向轴与全局轴同向（防大折点翻面成蝴蝶结白斑）。`depthTest:true /
  depthWrite:false / additiveLight / renderOrder 12`——弧在身体前后按 z 真遮挡。
  **条带宽度是电光晕的容器**：常驻雷暴 `0.11–0.18 H`（收窄后不再糊成一团），
  爪痕 `0.26–0.30 × 立牌宽`。
- **真几何分叉**：`placeBranch` 从主折线中心线取点，甩出独立条带（起点在主线上、
  自身带折线、按长度收细、宽度为主雷的 26–50%）——不是着色器里画的假枝。
  分叉概率随用户反馈提高：第一根 92%、第二根 62%。
- **常驻雷暴 `makePlasmaStorm`**：6 道弧槽挂 `_rig`（跟随单位、yaw 对镜头）。
  锚点池按立绘剪影量取、全部落在身体/地面；每击**随机取对**：跨体弧左右对穿
  （62% 两端一前一后，中段穿体被真深度裁掉 = 绕身），竖弧肩/背↔脚边地面；
  约 45% 反向放电让首尾粗细互换。**场次节奏**（雷云间歇）：一场 1–5 道、场内
  错峰 0–110ms，场间指数分布（P1 均值 4s / P2 均值 2s，方差大、偶有长静默）；
  每道 160–300ms 寿命 + 激发窗沿弧流动，场外彻底安静。**槽池只从当前可显示的
  槽里抽**（旧版从全 6 槽抽，低 level 常抽到被隐藏的槽 → 整场无可见电）。
  level = max(rage/6, P1 0.16 / P2 0.5)；pulse/burst 点放（burst 强制开一场）。
  弧中段 50% 概率甩 2–3 粒 GPU 电火花。
- **一次性件**：`plasmaSlash`（爪痕雷：size = **目标立牌可见宽** `unitW`，不按体高
  ——窄体型骑士按体高会把痕甩到身体两侧的空气里；三道依次错峰 26/34ms 出爪、
  各自淡出，中间粗两头细）、`plasmaBurst`（命中点短雷，中心粗梢头细，共用一份
  材质）、`skyBolt`（主弧 + 两道分叉，自画面上方劈落）、`lightningRing`（贴地锯齿
  雷环 + 环缘八道竖雷）。
- **deps 新口**：`renderCamera`（真渲染相机，雷面片朝向）——`_spellDeps` 与
  `fxServices` 都补了；命中拍 args 补 `source`（攻击方视图，Boss 按阶段分档）；
  `bossStateFx` 导演第三参 `{ particles }`（常驻件撒电火花）。
