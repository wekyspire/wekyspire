# 卡面特效层（CardFxLayer）抽象 + 冷却/衰败整合方案

## 目标

把 CardObject 上散落的叠加特效（冷却脉冲 overlay、咏唱边缘流光、未来的卡面特效）抽象为统一的**卡面特效层**；冷却与反向冷却（衰败）整合进该层并差异化：正向=绿脉冲，衰败=暗红脉冲 + 持久「衰败红纱」，另补齐「冷却中」的持久指示（现状卡面完全不显示冷却状态，只有 canUse 灰化）。

## 已勘察的现状锚点

- overlay 脉冲：`CardObject.ensureOverlay()`（z=0.4 加色面片）+ `BattleStage._pulseCard`（:1124，gsap tween 挂在 `overlay.userData.fxTween` 上——外部寄生状态）；仅 2 个调用点（powerUp 金 0xffd34c / 冷却绿 0x66ff99）。
- 咏唱流光：`_glowDot`（z=0.6）+ `updateGlow(dt)`，BattleStage 每帧全量 `view.updateGlow(dt)`（:216），状态由 `_syncCardContents` 差分驱动（:498）。
- 焚毁燃烧：着色器挂 `_face.material.onBeforeCompile` + 余烬 Points——**机制不同（牌面本体侵蚀），不迁入特效层**。
- 衰败（`decayCooldown`）**无播报**，前端只能靠 sync 快照差分感知；`cooldownTick` 载荷只有 `{skill}`，BattleStage:857 注释明言差异化着色待 delta。
- 投影已带 `remainingUses/currentCooldown/charges`（projectCardFull），`_syncCardContents` 的 card 对象可直接算冷却态——**无需改 faceSig/重烘卡面**。

## 改动清单

### 1. 新文件 `src/stage/objects/CardFxLayer.js`

卡面特效层：一个 THREE.Group（挂为 CardObject 子节点），统一管理牌面上方叠加特效。**时间驱动（内部 `update(dt)` 推进），不依赖 gsap/tween 注入**——脉冲/呼吸/流光轨道全是自算时间线，消灭 `overlay.userData.fxTween` 外部寄生。

```js
export class CardFxLayer {
  constructor({ width, height })          // 平面尺寸 = 卡面，各特效按需外扩
  pulse({ color, durationMs = 220, scale = 1.2 })   // 一次性加色闪光（幂等重触发：kill 当前时间线）
  setCooling(mode)                        // null | 'cooling' | 'decayed'：持久呼吸盖纱（另一张低透明平面）
  setEdgeGlow(on)                         // 咏唱边缘流光（迁移自 setActiveGlow/_glowDot/perimeterPoint）
  clearTransient()                        // 焚毁等接管牌面时熄灭全部叠加（替代 startBurn 里的散装清理）
  update(dt)                              // 帧驱动：脉冲进度 / 盖纱呼吸 / 流光轨道
  dispose()
  get hasEdgeGlow()
}
```

实现要点：
- 三张惰性平面分层：**veil 纱 z=0.35**（呼吸透明度 ~0.08-0.18，冷却态持续显示；色：冷却=青蓝、衰败=暗红 `0xc87070` 与 named 术语同色）→ **pulse 闪 z=0.45**（透明 0.55、scale 1.2→1.0，同现行为）→ **edge glow 点 z=0.6**（沿牌边 +1.6 外扩矩形轨道，≈2.9s/圈，同现参数）。
- `setCooling` 幂等（mode 不变不重建）；呼吸周期与脉冲互不干扰（各自平面）。

### 2. `src/stage/objects/CardObject.js` — 组合与门面

- 构造时 `this.fx = new CardFxLayer({ width: cardWidth, height: cardHeight })`，`this.add(this.fx)`。
- 删除 `_overlay`/`ensureOverlay`/`_glowDot`/`_glowT`/`setActiveGlow`/`updateGlow`/`perimeterPoint` 实现，保留薄门面（调用点少改）：`setActiveGlow(on)` → `fx.setEdgeGlow(on)`；`hasActiveGlow` → `fx.hasEdgeGlow`；新增 `updateFx(dt)` → `fx.update(dt)`。
- `startBurn`：`this.fx.clearTransient()` 替代现两行散装清理；`dispose()`：`fx.dispose()` 替代 overlay/流光的逐项释放。
- 类头注释补特效层说明（z 层次表）。

### 3. core — 冷却播报带方向

- `SkillCooldownInstruction`（skill.js:189）：`cooldownTick({ skill, delta: 1 })`（正向推进）。
- `decayCooldown(ctx, skill, def)`（bodySkills）：反向推进后 `ctx.presenter?.cooldownTick?.({ skill, delta: -n })`；斩/蓄力斩订阅 react 改传 `(instr, ctx)`。（`accelerateCooldown` 卡内加速暂不播报，留待需要时同款加 delta。）

### 4. `src/stage/stages/BattleStage.js` — 驱动接线

- 每帧循环（:216）：`view.updateGlow(dt)` → `view.updateFx(dt)`（burn 循环不动）。
- `_pulseCard(id, color)`（:1124）瘦身为 `obj.fx.pulse({ color })` 的 id 解析壳（powerUp/冷却两调用点不变）。
- `ANIM_COOLDOWN_TICK` 分支（:856-861）：`payload.delta < 0 ? 0xc87070（衰败红，与术语色一致） : 0x66ff99（绿）`，仍立即 finish（non-blocking）；删「待 delta」TODO 注释。
- `_syncCardContents`（:476-500）：对 hand/chant 卡差分冷却态——
  ```js
  const max = card.charges?.max ?? Infinity;
  const cooling = card.remainingUses < max;
  const decayed = cooling && card.currentCooldown > (card.charges?.cooldownTurns ?? 0);
  view.fx.setCooling(decayed ? 'decayed' : cooling ? 'cooling' : null);
  ```
  （无充能卡 remainingUses=Infinity 恒 null；deck/discard 卡不经 contents 同步，天然不显示。）

## 不做什么

- 焚毁燃烧（牌面着色器 + 余烬粒子）不迁入特效层——机制不同（侵蚀牌面本体 vs 叠加），且已有独立测试锚定。
- `accelerateCooldown`（猛拳加速）不播报、盖纱呼吸参数/脉冲时长/颜色仅给保守默认值——视觉调参由用户浏览器验收后随时改常量。
- 不改 faceSig/卡面烘焙（冷却态走 overlay 层，不占 canvas 重烘）。
