# 技能设计准则
* 优先设计系列技能，系列技能和单卡技能的比例建议为（1系列:1单卡）。
* 技能分9类，其中4主系，5附系（有特点的散卡为主，不能当主体系），列灵脉类技能各有侧重元素，主系类内技能依靠侧重元素紧密交互，通用类技能多为强大的单卡。
* 同主系类技能内还分体系，一般为2个体系，体系内交互最为紧密，体系间交互相对少。
* 体系卡池需要主动解锁才能获得，获得体系内**精英能力**后，体系内深入卡才会开始出现在卡池中。一局游戏一般后期可解锁共两个体系卡池。
* 体系内有**深入**卡，此类卡牌效果强力，仅在玩家于体系内有较深造诣且获得**精英能力**后才会出现在卡池中，一般无法跨类获取。
## 养成与等阶
* 卡牌晋升阶梯为 **D → C → B → A** 四档；**S（特级卡）**与 **Z（诅咒卡等）**单列、均不在阶梯上。S 为稀有强卡（Boss/精英专属、转化产物等），一般不可晋升也不可被晋升获得；Z 为诅咒/负担类卡牌。
* 相邻等阶之间一般是数值提升，有时数值提升会发生机制跃升，机制跃升一般只发生一次，同系列卡的骨架和定位大致都是相同的。

## 技能类和元素分配
### 火灵脉
_高风险，高收益_
**燃烧、蓝耗、焚卡**
* 注重爆发和伤害，高蓝耗，高副作用。
* 代表技能：点火（赋予燃烧），火球术（2蓝25伤抽2），爆燃（翻倍所有场上燃烧），
* 代表咏唱卡：燃心决（自燃换取魏启），小爆裂术（4蓝，咏唱期间，你耗蓝就转为此卡伤害）
* 代表能力：**烈焰亲和**降低燃烧对自身伤害，**炎魔**在造成伤害时施加燃烧。
#### 爆炎组合
**高蓝耗，高伤害**
* **火球术**系列造成中伤害并稳定过牌，可多次打出。
* **添柴**系列消耗卡，焚毁手中卡牌转化为魏启。
* **爆裂术**系列卡咏唱大群伤，咏唱期间，耗蓝越多，伤害越高。
* 深入：**放手一搏**消耗卡，抽5，焚毁牌库，获得大量魏启。
* 深入：**回响烈焰**，坟地越大，回魏启越多。
* 咏唱：**突破极限**，你在蓝量大于0时，可以透支蓝量出牌。
* **精英能力**：**爆发**，群伤技能只命中一个敌人时，其受1.5倍伤害。
* **大师能力**：**大师起手**，战斗中你打出的第一张火灵脉攻击牌获得双倍伤害。
#### 叠炎组合
**叠燃烧，燃烧是资源，也是诅咒**
* **点火**稳定上燃烧并造成伤害。
* **火墙**获得护盾，在自身有燃烧时获得更多护盾。
* **焰愈**治疗自己，燃烧越高治愈能力越强。
* **焚天**翻倍场上所有燃烧层数。
* **控火术**系列卡，通用燃烧效果利用。
* 精英能力：**灼脉术**，自身燃烧提供灵能加成。
* 大师能力：**避火术**，减免12点燃烧伤害。
* 咏唱：**燃心决**，每回合获得大量灵能和燃烧，不可主动解除。
#### 通用
* **火源归一**消耗卡，吸纳场上所有单位燃烧于己身，获得其层数倍数的护盾。
* 咏唱：**火焰精通**，每消耗魏启时获得护盾。

### 木灵脉
**恢复、卖血、持久战**
* 高贵的罕见恢复能力，叠毒，可以玩血条蹦迪，强大的不灭能力，有兜底容错
* 代表技能：塞西莉亚奇迹（3回合不死）、自救（咏唱，将死时大治疗并焚毁）、瘴气（叠毒）
* 代表咏唱卡：生息术（每回合强恢复）

### 空灵脉
**咏唱、增强、自动化**
* 大牌库享受者，能开很多咏唱卡，特殊的免伤方式，有直接从牌库打牌的方式
* 代表技能：自在（手牌上限扩容）、漂浮（从牌库抽卡并发动）、闪空灭（高AP多重攻击）
* 代表咏唱卡：登天术（每回合获得闪避）

### 体修
**操作你**
* 基础卡体系，有三个子体系（比寻常体系多一个），对卡组构建要求很高，大成天下无敌
* 代表技能：崩拳（出牌）、摘星手（牌序格挡）、斩（养刀）、真拳（过牌）
### 通用
* **早有准备**系列消耗型功能卡，无消耗抽多张牌。
* **翻箱倒柜**系列功能卡，消耗AP抽多张牌。
* **超越**系列消耗型功能卡，以滞气为代价换取额外行动力补充。
* 深入：**归元秘术**系列消耗性功能卡，减少或重置换牌行动力消耗。
* 深入：**真空斩**系列卡牌，造成较高伤害，并向牌库随机插入虚无。
* 深入：**一代宗师**系列消耗性功能卡，立刻获得高额格挡。
* 精英能力：**武神**，手牌上限 +2。
#### 拳组合
**过牌**
依靠过卡和低AP出牌反复使用技能造成大量伤害。
* **真拳**是罕见的同时0开销且无冷却技能，只要能反复回手则能打出高额伤害。
* **崩拳**基础冷却长，但在手中且使用技能时即刻冷却，依赖高强过牌和低费出牌提升输出频率。
* **敏捷连击**系列卡牌造成伤害，并且在手牌中最左侧时打出可以大量抽卡。
* **一瞬千击**系列卡牌向牌库增加价值（0AP消耗卡），多抽多得。
* **虚形拳**作为最后手牌出手时，暴击并补充手牌。
* 深入：**万变拳**系列卡牌以0AP打出任意手牌。
* 深入：**假动作**系列卡牌0AP抽大量牌并向牌库随机插入等量虚无（虚无是0开销、无效果卡牌）。
* 深入：**狂拳**系列消耗性卡牌损失自身生命造成高额伤害并抽卡。
* 咏唱：**无双**，抽卡即可造成伤害。
* 咏唱：**太极**，每打3张牌，抽1张牌。
  * 深入分支：**混元**，每弃3张牌，抽1张牌。
  * 深入分支：**无量**，每抽11张牌，回复1行动力。
* 精英能力：**拳师**，每回合打出第5张卡后，回复1行动力。
* 大师能力：**拳王**，每回合打出第5、8张卡后，回复1行动力。
#### 刀组合
**卡序**
刀组合依靠控制卡序进行战斗，伤害卡有打出门槛，专注于小次数爆发输出，有时和拳法牌拮抗，但也能通过精心控卡进行合作，达到更高境界。
* **斩**系列（进阶链顶点为断神斩）是本游戏最高伤害单卡，但条件苛刻——FIFO 循环下打出回牌库底是全局通则，斩的苛刻在于**仅在牌库中冷却充能**（牌库即刀鞘）；在手渡过回合则**衰败**：冷却计时反向推进。
* **风暴刀舞**系列是功能和伤害型卡牌，丢弃左侧所有牌，每丢一张造成伤害。
  * 分支：**优雅刀舞**系列依赖弃牌获得格挡和护盾。
  * 分支：**完美花刀**能造成伤害并选一张牌丢弃。
* **回旋斩**系列可以快速低费从**牌库末**抽牌。
* **刀背打击**系列可以从右手边丢牌。
* **呼吸**系列消耗性功能卡能让本回合内丢牌时带来正向作用。
* **飞刀**系列依赖条件发动和丢弃牌造成高额单次伤害。
* **藏锋**系列消耗性功能卡，造成高额伤害并获得滞气。
* 深入：**开刃**系列消耗性功能卡，即刻冷却手中刀法牌，回合结束时自动进入牌库。
* 深入：**斩灭**系列消耗性功能卡，下一次伤害必中且翻倍，回合结束时自动进入牌库。
* 深入：**锻刀**系列消耗性功能卡，锻造一张手中刀法牌并丢弃，回合结束时自动进入牌库。
* 咏唱：**养刀术**，系列持续提升牌库中刀组合卡牌的强度
* 咏唱：**刀法**系列回合开始时抽并自选2牌丢弃。
* 精英能力：**刀客**，换卡开销不超过 1。
* 大师能力：**刀圣**，每打出一张刀法牌抽 1。
#### 拆组合
**格挡**
拆组合和拳与刀联动，侧重防御、体系功能性补全，一般不在核心地位，但如果开发得当也能造成不俗的伤害。
* **摘星手**系列依赖卡序释放（完美条件），命中后稳定获取格挡；2026-09-14 重做：伤害削至每AP对标拳系白板（精准一击 12/2AP≈基础拳、精心一击 10/1AP≈快拳），命中给格挡下放全系列（1 层起步），高阶梯度＝揽云手与折杨同伤 23 但格挡 2（小质变）、摘星手 30 伤格挡 2（S 卡要强度）。
* **贯心**系列将格挡高效转化为伤害，适合消费溢出的格挡和绝杀。
* **盾**系列提供格挡、抽牌、手牌数加成的护盾，但并不太强，补足此体系缺乏自保的尴尬。
* **碎击**系列利用格挡提供多种负面、压制效果，补足一些相关短板。
* 咏唱：**以无胜有 / 以有胜无**，结束回合时，若没有/有许多手牌，获得高额格挡。
* 咏唱：**天一姿态**，格挡转化为攻击加成，**神龟姿态**，格挡再生。
* 精英能力：**武者**，格挡在3层及以上时，改为减免75%伤害。
* 大师能力：**武帝**，格挡在3层及以上时，改为减免90%伤害。

### 附：雷灵脉
**伤害、冷却、行动力小单卡，透支牌库纯净度**
* **光越**顷刻彻底冷却所有手牌，洗入2虚无。
* **磁控术**弃任意张卡，每2张获得1AP。
* 咏唱：**雷诀**，伤害随机敌人，洗入虚无，牌库越大伤害越高。
* 咏唱：**磁擎**，激活后获得高额力量加成，激发时洗入虚无。

### 附：水灵脉
**独特、控制**
* **凝灭**暂时凝滞自身或敌人，免疫所有伤害，冻结所有状态，跳过结算。
* **洁涛**净化场上所有效果。
* **脆化**赋予敌人易伤。
* 咏唱：**析晶术**，激活时，总跳过某些结算阶段。

### 附：土灵脉
**护盾、防御、反伤，手牌压力**
* **山形拳**按照你护盾层数造成伤害。
* **地层壁垒**在一回合延迟后提供爆发护盾。
* **要塞**同时造成群伤和护盾，每次打出后其数值提升。
* 咏唱：**岩化术**，每回合获得高额防御，代价是咏唱4。
* 咏唱：**山形**，你的护盾回合开始时不清空。
* 咏唱：**地刺**，激发时，荆棘3，撤下时清空荆棘。

### 附：光灵脉
**极端单卡**
* **太阳耀斑**烧尽牌库，造成随机天量多重伤害。
* **彩色棱镜**发现随机体系与此卡同阶的随机卡。
* **无限棱镜**变换每张手牌为同体系同阶随机卡。
* **世界**抽满手牌，按顺序全部发动。（注意，此处是直接发动（无开销），不是打出）
* **光之形**耗尽护盾、血量、所有效果层数之和N，发现【形】：伤害N。你留1血。
* **飞升**选卡令其所有数值翻倍。（这需要将大量卡牌中写死的数值字段变成卡牌成员量）

### 附：暗灵脉
**减益、过牌、牌序**
* **凝视**赋予虚弱。
* **帽子戏法**弃掉手牌中有开销的卡，并抽等量卡。
* **寂灭斩**按照敌人效果层数增伤。
* **侵蚀**将某敌人负面效果扩散到所有敌人。
