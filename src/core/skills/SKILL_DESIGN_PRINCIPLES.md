# 卡牌设计准则
* 优先设计系列卡牌，系列卡牌（series）和单卡卡牌的比例建议为（1系列:1单卡）。
* 大部分卡牌分为9个体系（system），其中4主体系，5附体系（有特点的散卡为主，不能当主体系）。
  * 主体系分别为：火、木、空、体修。副体系分别为：水、地、雷、光、暗。
  * 未纳入体系分类的余下卡牌为：通用卡、特殊卡、Z卡。
  * 每个体系内的卡牌各有侧重元素，主系类内卡牌依靠侧重元素紧密交互。
  * 通用类卡牌多为强大的单卡。特殊卡为特殊作用的卡。Z卡一般为诅咒卡和负面效果卡。
* 主体系内卡牌内还分子体系（subsystem），一般主体系内有2个子体系，子体系内交互最为紧密，子体系间交互相对少。
* 主体系内，不在任意子体系内的卡为体系通用卡。
* 主体系内有子体系的**深入**卡，此类卡牌效果强力，仅在玩家获得主体系中对应子体系的**精英能力**后才会出现在卡包卡池中。
## 养成与等阶
* 卡牌晋升阶梯为 **C、B、A** 三档，并通过相同的晋升网络组成一个又一个系列（series），部分卡牌系列有**S（特级卡）**，但它们不可在训练营地晋升获得而只能通过特殊渠道晋升获得。
  * A到S的晋升不必是无副作用的超集升级，而应该是相同机制的数值或者再次机制**飞跃**。S 卡可以强化负面效果和代价！
  * C到A的晋升一般是数值的改善或副作用的减缓，但A到S的晋升定位是**卡牌系列之机制的终极体现**。
* **Z**级卡不在晋升阶梯上，正常情况下也不会从卡包内出现。Z 一般为诅咒/负担类卡牌，有诅咒（curse）、负担（burden）两个子体系分类。除此之外还有X等级卡（仅断神斩一张）。
* 相邻等阶之间一般是数值提升，有时数值提升会发生机制跃升，机制跃升一般只发生一次，同系列卡的骨架和定位大致都是相同的。

## 卡牌类和元素分配
### 火灵脉
_高风险，高收益_
**燃烧、蓝耗、焚卡**
* 注重爆发和伤害，高蓝耗，高副作用。
* 代表卡牌：点火（赋予燃烧），火球术（抽卡伤害一体），焚天（翻倍燃烧），
* 代表咏唱卡：燃心决（自燃换取魏启），小爆裂术（咏唱期间，你耗蓝就转为此卡伤害）
* 代表能力：**烈焰亲和**降低燃烧对自身伤害，**炎魔**在造成伤害时施加燃烧。

### 木灵脉
**恢复、卖血、持久战**
* 高贵的罕见恢复能力，叠毒，可以玩血条蹦迪，强大的不灭能力，有兜底容错
* 代表卡牌：塞西莉亚奇迹（3回合不死）、自救（咏唱，将死时大治疗并焚毁）、瘴气（叠毒）
* 代表咏唱卡：生息术（每回合强恢复）

### 空灵脉
**咏唱、增强、自动化**
* 大牌库享受者，能开很多咏唱卡，特殊的免伤方式，有直接从牌库打牌的方式
* 代表卡牌：自在（手牌上限扩容）、漂浮（从牌库抽卡并发动）、闪空灭（高AP多重攻击）
* 代表咏唱卡：登天术（每回合获得闪避）

### 体修
**操作你**
* 基础卡体系，有三个子体系（比寻常体系多一个），对卡组构建要求很高，大成天下无敌
* 代表卡牌：崩拳（出牌）、摘星手（牌序格挡）、斩（养刀）、真拳（过牌）

### 附：雷灵脉
**伤害、冷却、行动力小单卡，透支牌库纯净度**
* **光越**顷刻彻底冷却所有手牌，洗入2虚无。
* **磁控术**弃任意张卡，每2张获得1AP。
* 咏唱：**雷诀**，伤害随机敌人，洗入虚无，牌库越大伤害越高。
* 咏唱：**磁擎**，激活后获得高额力量加成，激发时洗入虚无。

### 附：水灵脉
**独特、控制**
* **凝灭**暂时凝滞自身或敌人，免疫所有伤害，冻结所有状态，跳过结算。
* **洁涛**净化场上所有效果。
* **脆化**赋予敌人易伤。
* 咏唱：**析晶术**，激活时，总跳过某些结算阶段。

### 附：土灵脉
**护盾、防御、反伤，手牌压力**
* **山形拳**按照你护盾层数造成伤害。
* **地层壁垒**在一回合延迟后提供爆发护盾。
* **要塞**同时造成群伤和护盾，每次打出后其数值提升。
* 咏唱：**岩化术**，每回合获得高额防御，代价是咏唱4。
* 咏唱：**山形**，你的护盾回合开始时不清空。
* 咏唱：**地刺**，激发时，荆棘3，撤下时清空荆棘。

### 附：光灵脉
**极端单卡**
* **太阳耀斑**烧尽牌库，造成随机天量多重伤害。
* **彩色棱镜**发现随机体系与此卡同阶的随机卡。
* **无限棱镜**变换每张手牌为同体系同阶随机卡。
* **世界**抽满手牌，按顺序全部发动。（注意，此处是直接发动（无开销），不是打出）
* **光之形**耗尽护盾、血量、所有效果层数之和N，发现【形】：伤害N。你留1血。
* **飞升**选卡令其所有数值翻倍。（这需要将大量卡牌中写死的数值字段变成卡牌成员量）

### 附：暗灵脉
**减益、过牌、牌序**
* **凝视**赋予虚弱。
* **帽子戏法**弃掉手牌中有开销的卡，并抽等量卡。
* **寂灭斩**按照敌人效果层数增伤。
* **侵蚀**将某敌人负面效果扩散到所有敌人。
