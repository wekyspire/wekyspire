# 技能设计准则
* 优先设计系列技能，系列技能和单卡技能的比例建议为（1系列:1单卡）。
* 技能分9类，其中4主系，5附系（有特点的散卡为主，不能当主体系），列灵脉类技能各有侧重元素，主系类内技能依靠侧重元素紧密交互，通用类技能多为强大的单卡。
* 同主系类技能内还分体系，一般为2个体系，体系内交互最为紧密，体系间交互相对少。
* 体系卡池需要主动解锁才能获得，获得体系内**精英能力**后，体系内深入卡才会开始出现在卡池中。一局游戏一般后期可解锁共两个体系卡池。
* 体系内有**深入**卡，此类卡牌效果强力，仅在玩家于体系内有较深造诣且获得**精英能力**后才会出现在卡池中，一般无法跨类获取。
## 养成与等阶（2026-08-02 定调）
* **等阶 4+1+1 档**：晋升阶梯为 **D → C → B → A** 四档；**S（特级卡）**与 **Z（诅咒卡等）**单列、均不在阶梯上。S 为稀有强卡（Boss/精英专属、转化产物等），不可晋升也不可被晋升获得；Z 为诅咒/负担类卡牌。旧 11 档（含 +/- 细分）作废——相邻细分档没有身份差异，只是数值微调。
* 相邻等阶之间必须是**机制/玩法跃迁**（改名、换卡面、换效果骨架），不只是数值提升。旧姿态链（武术→大师→真武）是正确范式。
* **升阶 = 局外 Transform**（换成链上下一档的卡定义，白名单操作）；系列归属用卡定义 `series` 字段串联；晋升方向允许分叉（一张卡的下一档可以有多个候选）。
* **废弃 powerUp 养成轴**：卡牌定义保持纯静态数据，不存在"半永久威力计数器"。局内数值漂移走 modification 系统（临时、结算时生效、不污染卡定义），局外永久成长只有等阶晋升。卡牌级 modifier 选项后续补上（目前 core 残留的 `power` 字段及相关测试为过渡实现，随 modifier 落地一并清除）。
## 咏唱双态模型（2026-08-28 定调，槽位机制已退役）
* 咏唱卡无槽区、无激活数上限，与普通卡同住四区（手牌/牌库/焚毁/结算区；牌库为 FIFO 唯一循环区，无弃牌堆）。双态：未激活（计 1 张手牌）与已激活（按咏唱值 chantWeight 计多张手牌——咏唱与手牌压力统一为同一资源）。
* 打出未激活咏唱 = 付费发动：回手落原位并点亮，玩家获得其 activated 能力；发动合法性 = 激活后加权手牌数 ≤ 手牌上限（player.maxHandSize，默认 7），满手后抽牌也不进。
* 打出已激活咏唱 = 免费解除：熄灭并按卡牌特性离场（消耗→焚毁，否则→牌库），压力随离手释放。任何离手路径（弃/焚/移/转化）统一熄灭——「激活只在手牌中成立」。
* anchored（锁定）语义更新：不可**主动**解除（连免费关停都不行）；被弃等离手熄灭是物理事实，不受锁定保护。

## 技能类和元素分配
### 火灵脉
**燃烧、灵能、焚卡**
* 注重爆发和伤害，高蓝耗，高副作用
* 代表技能：太虚绝炎（9蓝爆发伤害）、无上神炎（多功能叠火、焚卡、净化）、陨落星炎（1蓝高伤，给自己叠火）【焚卡+自伤已验证·原型：test/fireVein.test.js】
* 代表咏唱卡：灼脉术（燃烧转灵能）【已验证·原型：施加燃烧→集中订阅；集中/火焰主宰走 getStat 面板读轨（含跨实体 view 衍生），test/panelModifiers.test.js】
#### 爆炎组合
**主叠灵能，以爆裂术为核心**
* **火球术**系列造成中伤害并稳定的叠灵能卡，可多次打出。
* **添柴**系列消耗卡，焚毁手中卡牌转化为魏启。
* 深入：**内燃**消耗卡，焚毁所有手牌并按焚卡数获得节能。
* **爆裂术**系列卡固有、固定8蓝大额群伤，能一发大幅削弱敌人或直接结束战斗，若能打出多发则胜券在握。【已验证·原型：群伤 tags 标记，test/elementalBurst.test.js】
* 深入：**太虚绝炎**是立马起手的9蓝超高群伤技能。
* 咏唱：**突破极限**，你在蓝量大于0时，可以使用超出你所能负担蓝耗的技能。【已验证·原型：能力可用性裁决链+消耗 clamp，test/elementalBurst.test.js】
* **精英能力**：**爆发**，群伤技能只命中一个敌人时，其受1.5倍伤害。【已验证·原型：tags filter+存活数判定，test/elementalBurst.test.js】
* **大师能力**：**大师起手**，战斗中你打出的第一张火灵脉攻击牌获得双倍伤害。
#### 叠炎组合
**主叠燃烧，以控火术为核心**
* 精英能力：**灼脉术**，自身燃烧提供灵能加成。
* 大师能力：**避火术**，减免12点燃烧伤害。
* 咏唱：**燃心决**，每回合获得大量灵能和燃烧，锁定（anchored）不可主动解除。【已验证·原型：双态模型下 anchored 挡免费关停 + 离手照常熄灭，test/swapCard.test.js】
#### 通用
* **无上神炎**系列卡，使用后发现三选一零费消耗卡：**炙燃**，**炼解**，**净化**，分别可以给自己和一对手叠大量燃烧、选一卡烧毁并获得节能，消除一负面状态。
* **集焰**系列消耗卡，吸纳场上所有单位燃烧于己身，获得其层数倍数的护盾。
* 精英能力：**火焰精通**，每消耗魏启时获得护盾，造成伤害时赋予燃烧。

### 木灵脉
**恢复、中毒、持久战**
* 高贵的罕见恢复能力，叠毒，但效果和机制手段较为单一，其它手段有限
* 代表技能：塞西莉亚奇迹（3回合不死）【已验证·原型：不灭=minHp 地板读轨，test/damageLifecycle.test.js】、复苏（瞬间强治疗）、炼髓毒（叠毒）
* 代表咏唱卡：生息术（强恢复，但卡牌不再自然冷却）
### 空灵脉
**闪避、增强、回蓝**
* 生存和辅助能力极强，攻击手段相对有限
* 代表技能：自在（手牌上限扩容）、璀璨升阶（自选锻卡）、闪空灭（多重攻击）
* 代表咏唱卡：登天术（闪避）【闪避机制已验证·原型：PRE 归零+递减，test/damageLifecycle.test.js】
### 体修
**过牌、卡序、格挡**
* 基础卡发展而来的体系，有三个子体系（比寻常体系多一个）。因此若要展现优势强度，对卡组构建要求很高。
* 代表技能：崩拳（出牌）、摘星手（牌序格挡）、断神斩（养刀）、真拳（过牌）
* 代表咏唱卡：天一姿态（格挡转攻击）
### 通用
* **早有准备**系列消耗型功能卡，无消耗抽多张牌。
* **翻箱倒柜**系列功能卡，消耗AP抽多张牌。
* **超越**系列消耗型功能卡，以滞气为代价换取额外行动力补充。【已验证·原型：0费回AP+滞气锁当回合抽牌（滞气语义见 test/bodySkills.test.js 收刃用例）】
* 深入：**归元秘术**系列消耗性功能卡，减少或重置换牌行动力消耗。【已验证·原型：重置 swapCount，test/swapCard.test.js】
* 深入：**真空斩**系列卡牌，造成较高伤害，并向牌库随机插入虚无。【已验证·原型：AddCardInstruction rng 随机落点，test/deckCraft.test.js】
* 深入：**一代宗师**系列消耗性功能卡，立刻获得高额格挡。【未实现】
* 精英能力：**武神**，手牌上限 +2（咏唱槽时代「加槽」的继任者：扩容 = 更多咏唱压力空间）。【已验证·原型：onBattleStart 改 maxHandSize，test/swapCard.test.js】
#### 拳组合
**过牌**
依靠过卡和低AP出牌反复使用技能造成大量伤害。
* **真拳**是罕见的同时0开销且无冷却技能，只要能反复回手则能打出高额伤害。
* **崩拳**基础冷却长，但在手中且使用技能时即刻冷却，依赖高强过牌和低费出牌提升输出频率。
* **敏捷连击**系列卡牌造成伤害，并且在手牌中最左侧时打出可以大量抽卡。
* **一瞬千击**系列卡牌向牌库增加价值（0AP消耗卡），多抽多得。
* **虚形拳**作为最后手牌出手时，暴击并补充手牌。
* 深入：**万变拳**系列卡牌以0AP打出任意手牌。【已验证·原型：嵌套 UseSkillInstruction+costOverride 费用豁免，test/nestedPlay.test.js】
* 深入：**假动作**系列卡牌0AP抽大量牌并向牌库随机插入等量虚无（虚无是0开销、无效果卡牌）。【已验证·原型：抽N插N随机落点，test/deckCraft.test.js】
* 深入：**狂拳**系列消耗性卡牌损失自身生命造成高额伤害并抽卡。【未实现】
* 咏唱：**无双**，抽卡即可造成伤害。
* 咏唱：**太极**，每打3张牌，抽1张牌。【已验证·原型：跨回合计数订阅，test/chantCounting.test.js】
  * 深入分支：**混元**，每弃3张牌，抽1张牌。【已验证·原型：跨回合计数订阅，test/chantCounting.test.js】
  * 深入分支：**无量**，每抽11张牌，回复1行动力。【已验证·原型：跨指令抽牌计数+余数保留，test/apEngines.test.js】
* 精英能力：**拳师**，每回合打出第5张卡后，回复1行动力。【已验证·原型：history.turn.played 回合内计数，test/apEngines.test.js】
* 大师能力：**拳王**，每回合打出第5、8张卡后，回复1行动力。【已验证·原型：history.turn.played 回合内计数，test/apEngines.test.js】
#### 刀组合
**卡序**
刀组合依靠控制卡序进行战斗，伤害卡有打出门槛，专注于小次数爆发输出，有时和拳法牌拮抗，但也能通过精心控卡进行合作，达到更高境界。
* **斩**系列（进阶链顶点为断神斩）是本游戏最高伤害单卡，但条件苛刻——FIFO 循环下打出回牌库底是全局通则，斩的苛刻在于**仅在牌库中冷却充能**（牌库即刀鞘）；在手渡过回合则**衰败**：冷却计时反向推进。两者均为 named 术语（`core/skills/namedTerms.js`，卡面只写短词、长机制进 tooltip：`X伤害，衰败N，斩`）。进阶链走 `battlePromotesTo`（局内转化专用字段）——**斩不可局外晋升**（营地/训练场的 promoteCard 只认 `promotesTo`，对斩链不可见，用户 2026-09 定）。【已验证：cooldownZones+回合开始衰败订阅，test/bodySkills.test.js「斩」用例；局外不可晋升见 test/bladeSkills.test.js】
  * 分支：**强斩**系列，条件不太苛刻，但伤害也相对平凡一些。【未实现】
* **风暴刀舞**系列是功能和伤害型卡牌，丢弃左侧所有牌，每丢一张造成伤害。
  * 分支：**优雅刀舞**系列依赖弃牌获得格挡和护盾。【未实现】
  * 分支：**完美花刀**能造成伤害并选一张牌丢弃。
* **回旋斩**系列可以快速低费从**牌库末**抽牌。【已验证·原型：DrawCardsInstruction from:'bottom'，test/bodySkills.test.js「回旋斩」用例】
* **刀背打击**系列可以从右手边丢牌。【已验证·原型：丢最右跳过自身，test/bodySkills.test.js「刀背打击」用例】

  * 分支：**坚强呼吸**同时能获得护盾。【未实现】
  * 分支：**柔韧呼吸**同时能获得力量。【未实现】

* **飞刀**系列依赖丢弃两侧牌造成高额单次伤害。【已验证·原型：handNeighbors+弃牌，test/bladeCombo.test.js】

* 深入：**开刃**系列消耗性功能卡，即刻冷却手中刀法牌，回合结束时自动进入牌库。【已验证·原型：TurnEnd POST once 订阅回库，test/deckCraft.test.js】

**格挡**

* **盾**系列提供格挡、抽牌、手牌数加成的护盾，但并不太强，补足此体系缺乏自保的尴尬。
* **碎击**系列利用格挡提供多种负面、压制效果，补足一些相关短板。
