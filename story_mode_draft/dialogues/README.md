## 说话人口径

| speaker 名 | 身份 | 语气要点 |
| --- | --- | --- |
| `骑士` | 主角（实为塔主本人，全程不主动揭示） | 冷峻、寡言、**口语化**——像普通人说话（"很难吃。""不。"）；虚无主义**自嘲**（嘲的是自己："有几道是自己砍的"）；**较少挖苦**（挖苦是例外，不是常态）；可说可不说一律不说（写作`骑士：...`）；**塔顶"心软"交出钥匙之前，没有任何温情输出**——不安慰、不鼓励、不道谢、不许诺；B/C 路线（交钥匙后）温情解禁，仍以动作为主、台词极简 |

| `塔主` | 字条 / 研究笔记的书写者（= 主角过去） | 四时期笔迹（见 NOTES_AND_MEMOS）；带"游戏开发者"式自嘲打破感；八张阿尔法装置字条是时期二的自信顶峰，**且其关于装置的论断全部为真**——他的悲剧是"全对仍然不够"，不是"狂妄被打脸" |

## remi 成长弧（三幕）

**总纲：它从"替别人守塔"长成"替自己找星"。转折点不是某一天，而是从它隐约意识到"寻找尖塔之星只能靠它自己"开始。**

1. **前期（1–11 层）**：笨、胆小、万事问骑士；战斗时躲在楼梯口喊加油；字条全靠骑士念；对维护程序的话照单全收。
2. **暗转（12–43 层）**：开始自己下判断——不再每场都躲（成长线 G1）、记敌人招式给骑士报错（G2）、第一次对维护程序撒谎（G3）；40 层字条坐实"一层根本没有守护者"的裂缝（G4），它自我消化，但从此不再追问别人"塔顶会有什么"；43 层说出成长宣言（G5："如果没有，我就自己找"）。
3. **成型（塔顶 → 结局）**：塔顶争执中第一次与人正面吵架且不让步（虽然辩不赢）；"能让我来动手吗"是它自己的主意；B/C 路线独自追逐塔楼程序直到冷却液河边——**"找星星只能靠我自己了"**；决战中仍会数手指，但数手指的意义变了（"以前是数着等你回来，今天是数着我也在现场"）。

**成长 ≠ 换人**：它依旧笨、依旧情绪化、依旧不识字（后期认得零星几个字）、依旧怕的时候数手指。成长体现在它**做事的主语**从"维护程序说 / 骑士说"变成了"我"。

## 写作防漂移（关键设定备忘）

写任何台词前对照本节；权威解释以 `string.md`「作家批注 · 结局 B 停机逻辑」为准。

- **装置字条恒真**（关键认知）：塔楼内关于阿尔法装置的所有字条**都是正确的**——装置确实完美，确认链路确实由因果保证，证明确实成立。失败不在装置、不在证明，而在证明的**前提**：答案不在"一切物质形式"的搜索空间内（终极意义是非物质之物）。塔主不是算错了，是**算对了仍然不够**。字条 5 自带兜底（"除非科学本身划上了一个问号"——第三种回答恰恰从问号里来）；字条 8 在 B/C 线被字面兑现（装置未停机，"无法找到答案的现实"确实没有发生——只是答案等塔主回来才完成确认）。因此骑士面对任何装置字条的口径是"不会错"，不是"他错了"。
- **超意识链路确认**：阿尔法装置的"命中"验证走塔主潜意识的因果链路；它只答真 / 假（字条 5）。
- **第三种回答 → 自锁**：装置枚举出瑞米时，链路返回了是 / 否以外的回答，装置**停止枚举但没有停机**（"害怕错过答案"）。塔顶监视器可见：尝试计数器定格在远超任何字条记录的数字上、**不再跳动**。骑士看到后最多"..."，**绝不用台词点破**——伏笔留给敏锐玩家。
- **停机绑定**：塔楼程序的停机当且仅当阿尔法装置停机（元逻辑写死；完全破解钥匙、重写元逻辑之前无法规避）。它在塔基赛跑的就是这件事。
- **结局 A 的消散**：拧钥匙 = 塔主作答"否" → 装置回收瑞米的物质并继续枚举（未及开始便随塔崩塌被毁）。因此结局 A（拒绝交钥匙的分支）里瑞米随钥匙转动消散为碎片与星光——**演出不给解释台词**。
- **确认的三时态**：A = 永不确认；B = 瑞米之死锁定主角未来的顿悟，链路把未来的"是"折回当下（装置"自主"停机，时间先后倒置）；C = 当下确认（纵身一跃）。**B 的停机不写任何解释台词**，全靠字条 3/7 让玩家自行合环；至多保留骑士一句"它问的，从来不是现在的我"。
- **主角身份**：全程不明示；头盔滚落前不写骑士面容神态；滚落时 remi 认出那张脸与"塔主大人"的形象**相去无多、只是苍老**。
- **程序的权限**：它在塔顶实验室楼层内无权操作、无法在游戏规则外攻击塔主（塔主编码的规则）——所以塔顶它只能哀求；44 层 Boss 战（最终战 A）中它能借 Boss 机制在游戏规则内出手，二者互为对照。

**侧写三件套（反直抒原则）**：文字不直接抒情——旁白不写比喻式抒情，台词不下情绪结论。
情绪由三条侧写通道承载：

1. **对话**——二人简洁的对话。remi 承载情绪表述；骑士口语化、给最小事实、痛处不答。
2. **幕间动态**——`> 幕间｜…` 视觉动态占位（美术资源后补，落为 `image` / `wipe` / `fade` 步骤）。
3. **音乐节奏变化**——`> 音乐｜…` 节奏 / 配器变化占位（音效资源后补，落为 `call` 钩子）。

**头盔铁律**：骑士全甲头盔盖住面容，塔基头盔滚落之前**任何场景不写骑士的表情、神态、眼神**；
他的情绪只能通过动作节拍（握刀、松手、回头、离开）与音乐变化侧写。
头盔滚落后（B/C 路线终盘）也只做最低限度的面容描写（"白发""苍老"），不写表情。

**骑士语言剪影**（台词验收三问）：
1. **是嘴里的话吗？**——用活的口语（"现学来的""多着呢""罢了""尽是"），不用书面语序、
   文艺定语与排比。念一遍不像人随口说的，删。
2. **是不是只给了最小事实？**——问哪答哪，不添画面、不替观众造意象
   （"字条上。"而非"一个爱写纸的人。"）。给得越少，谜越深。
3. **痛处挡住了吗？**——碰到真正痛的那一问，不答，反问或岔开
   （"你怎么尽是问题？""手滑。"）。悲剧感来自他在**哪一问上停嘴**，不来自他说了什么。
   自嘲同理：他的虚无主义首先指向自己（"呵呵"只对自己），对 remi 以沉默和岔开为主。
   温情在交钥匙前一律不得出现；交钥匙后（B/C 路线）用动作与例外时刻（"人还在就行"）表达。

## 剧本契约（与引擎一致）

- cutscene 步骤词汇表与 `src/shell/overlay/cutscenePlayer.js` 一致：
  `fade(ms)`、`wipe(coverMs?, revealMs?, atCover?)`、`image(src?, fadeInMs?, holdMs?, fadeOutMs?)`、
  `dialogue(pages: [{speaker, text}])`、`call(fn)`。
- CUTSCENES.md 中的剧本直接以 `{ id, steps: [...] }` 书写，可整段拷入 `scripts.js`；
  其中 `call` 步骤的 `fn` 只写注释占位（如 `fn: '$startFinalBossB'`），由装配层绑定。
- 对话页 `text` 中的括号动作为舞台提示，渲染时可作斜体样式。
