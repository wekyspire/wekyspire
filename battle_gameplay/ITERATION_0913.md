## 一、Hineven 的文档改动总结（FIRE_VEIN_CARDS.md + SKILL_DESIGN_PRINCIPLES.md）

### 1. 文档卫生：脱实现化

- 全量删除测试/实现注记（【已验证·原型：test/xxx】、【未实现】、【已实现：…】、日期定调戳）。
  设计文档只写**设计**，实现状态与验证口径归代码与 git。
- 删除已尘埃落定的机制专节（咏唱双态模型、powerUp 废弃声明）——定案即默认，不再占篇幅。

### 2. 等阶哲学反转（SKILL_DESIGN_PRINCIPLES 养成节）

- 旧铁律：「相邻等阶之间**必须**是机制/玩法跃迁，不只是数值提升」。
- 新口径：「相邻等阶之间**一般是数值提升**，有时数值提升会发生机制跃升，机制跃升一般
  **只发生一次**，同系列卡的骨架和定位大致都是相同的」。
- 解读：练刀链（D→C 威力跃迁、C→B 费用跃迁，其余纯数值）从特例升格为**系列设计默认式**——
  每条链最多一个跃迁点，不许层层换骨架。

### 3. 火灵脉：身份锐化

- 总纲加判词「**不要玩火，玩火必自焚**」；身份落点为「高蓝耗、高副作用，换取爆炸输出和极高跳伤」。
- 两体系一句话化：
  - **爆炎 = 蓝量引擎轰炸**（蓝足则不卡手、输出爆炸；没蓝就萎——资源语言从「蓝和咏唱」收窄为「蓝」）；
  - **叠炎 = 玩火**（燃烧是利剑、是矿藏、也是反噬的源泉；弱点从「副作用控制」直写「容易玩火自焚」）。

### 5. 后续灵脉路线图（SKILL_DESIGN_PRINCIPLES 附系全部具体化）

- **雷灵脉**：伤害/冷却/AP 小单卡 + **「虚无」代价语言**（洗入虚无 = 透支牌库纯净度）——
  光越（顷刻彻底冷却+洗2虚无）、磁控术（弃卡换AP）、雷诀（咏唱，牌库越大伤害越高）、
  磁擎（力量加成，激发洗虚无）。**雷 = 牌库纯净度的反面教材，与体修纯净度主题互为镜像。**
- **土灵脉**：护盾/反伤/手牌压力——山形拳（盾层转伤）、地层壁垒（延迟爆发盾）、要塞（群伤+盾、
  打出后数值成长）、岩化术（高防御咏唱4）、山形（护盾回合开始不清空）、地刺（荆棘开关）。
- **水灵脉**：独特控制——凝灭（凝滞免伤冻结）、洁涛（净化全场）、脆化（易伤）、析晶术（跳结算阶段）。
- **光灵脉**：**极端单卡群**——太阳耀斑（烧尽牌库随机天量多段）、彩色/无限棱镜（发现/变换）、
  世界（抽满手牌按序无开销发动）、光之形（耗尽一切换一发）、飞升（数值翻倍——依赖卡牌数值字段成员化）。
- **暗灵脉**：减益/过牌/牌序——凝视（虚弱）、帽子戏法（弃有开销卡抽等量）、寂灭斩（按敌效果层增伤）、侵蚀（负面扩散）。
- 体修修订：呼吸系改「正向作用」（原文笔误）；武帝「减免全部」→「减免90%」；
  删拔刀术/刃心两个未实现分支。

#### E（P1 太极链观察，9 层战败于精英伏击者+石茧）

1. **太极 every3 没有翻盘**：实测持续均值 4.0 打/回合（峰值 7，与 R8 一致），均衡点
   借力5=15打 / 化劲4=12 / 太极3=9（带共鸣石 10/8/6）——无共鸣石三件全亏，太极带石也 −0.67/回合，

   抽牌引擎的正确变现是抽→伤，不是抽→更多打（被 AP4 卡死）。**若链要成立，精通/无双应被视作链的第三件套。**
5. 均衡点定量版：全程挂太极 = 36 抽 vs 81 抽位成本，**净 −45**（带石 −27）。
6. 顺手情报：咏唱1·猛烈肘击（C）同为权重1先点亮件；精准一击完美实战可编排（2/2）；

- **AI 批次线（批次 1–4，已实装）= 结构性修账**：卡包制与门禁、跳过进阶平等化（+3血→删卡反哺）、
  斩链纯净度构筑件（拭刃/相刀）、Boss 生态分层（骑士长/饕餮/塔心 + 分级遗物掉落）、
  遗物经济可见度（售货机遗物包三选一）、数值意识铁律（新卡先对标同阶白板，彻底0费默认冷却1）。
  风格：**保守对标，先让账算得平**。
- **Hineven 文档线 = 身份锐化 + 收益端加码**：火系两体系一句话判词；补偿不给机制给数值
  （可燃血液盾+2 而非 cap）；自焚+1、火壁+15；深入卡做成**引擎与身份卡**
  （放手一搏焚牌库=把未来变现成蓝）；补体系闭环件（灭火自净、炼化炼解焚卡泵、背水一战）。
  风格：**风险明码标价，收益配得上风险**。

### 合流点（天然一致）

1. 双方都在把火系从「T1 但玻璃炮」推向「风险有价、收益够格」——R8「无即时大盾」的死因，
   文档线用火壁（0费 7+15 大盾）+ 可燃血液（11/15/15）直接回应，比我原稿（B 加成 11）更敢给。
2. 「彻底 0 费谨慎」铁律文档线也遵守（火盾/火墙 1AP 冷却1，仅火壁 0 费——B 阶身份位）。
3. 等阶哲学反转追认了练刀链模式，批次 4 新卡（拭刃/相刀单件无链）不冲突。

### 张力点（需要探讨）

1. **火墙链命名**：文档逐阶独立命名（火盾/火墙/火壁），实现是同名链（练刀式）。
   两个先例并存（练刀同名 vs 斩链异名）——火墙链跟哪个？
2. **放手一搏（焚牌库）的战线**：焚毁是局内口径，抽5+焚全牌库回蓝≈一回合终极爆发，
   与「澄明/澄空」（若有）之外的任何续航件互斥——它是「打完这张就只剩一只手」的卡。
   数值上 20+ 牌库 = 40+ 魏启，需要对决断窗口（什么时候炸）做保护性设计吗，还是就让它裸奔？
3. **火焰精通的归属**（精英能力 → 咏唱）：现有灼脉术/爆发等能力位格局要动吗？
4. **控火术：灭删除 + 灭火（自净）新增**：敌人燃烧驱散整个职能拿掉，叠炎对「敌盾/敌增益」的
   交互面变窄——确认是刻意收窄（燃烧只进不出，收益全在叠与翻倍）？
5. **雷灵脉「虚无」语言**与体修纯净度主题互为镜像——将来实装时，虚无卡是否进拭刃的
   焚毁豁免/相刀的翻牌口径需要提前定（虚无非刀法 → 拭刃烧虚无=纯赚？）。
6. **回复经济（R9 三连实锤，新议题）**：D（8/15）、B-P2（10/18）、F（23）全部死于
   「输出够用、血线磨穿」——P2 技术天花板也推不动，说明不是玩家问题而是结构问题。
   回复来源目前只有营地休整 + 20 金药剂 + Boss 回满。候选方向：营地/药剂量价上调、
   战斗内续航件扩容（焰愈系/土灵脉回复）、楼层血线消耗曲线本身下修。等 A/C 数据后定量。
7. **新内容曝光率（R9 三连 0 观测，新议题）**：太极（E）、相刀（D）、火墙/拭刃/相刀/太极（B）
   在正常局前 1/3 全部 0 样本——卡包制 + 等阶门禁把新件藏得太深。候选方向：新卡的保底
   曝光通道（商店货架加权/训练房定向/通用包注入率上调）、B/A 阶门禁的节奏前挪。
