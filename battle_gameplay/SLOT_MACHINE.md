# 老虎机
老虎机是一个特殊的战斗后房间 / 环节。玩家可以在此交换资源并获得稀有物品。关键词是资源交换。

形态上，老虎机由一个普通场景，中安放一台屏幕发光的老虎机和一旁的灰灰的银行机组成。玩家摇动老虎机时，场景转到老虎机屏幕面前，摇动和中奖时均有精致动画。

老虎机很慷慨，银行机很吝啬。花费金币可以在老虎机上roll来消费，老虎机的roll结果可能包含：符合你灵脉等级的任意卡牌包，额外roll，遗物，金币大奖，这些产出总是可以放弃不要的。

每个老虎机房间内的roll初始为5金一次，roll一次后价格上涨6金，但出现大奖的概率也会随之提升。

每在老虎机上累积roll一定次数后（7次），老虎机可以允许你投入一件遗物或一张卡牌，它将吞噬此遗物/卡牌，粉碎为价值相当的金币。然后累积次数重置。

小奖初始概率：18%，大奖初始概率：2%。每roll一次若没有中小奖，小奖概率+7%，中奖后重置。每roll一次若没有大奖，大奖概率+2%，中奖后重置。若小奖概率+大奖概率>100%，那么小奖概率在实际算中奖时计为（100% - 大奖概率）。

小奖类型包含：小部分状态恢复、正常卡包、任意一张高级卡（适配你的灵脉等级）、随机一张你可以升级的卡牌的升级后的复制品（你可选将其加入牌库，但不能替换原有卡）、任意一张低级（低于你目前等级的）灰色卡、随机C/B级遗物。小袋金币（10-30不等）、特殊物品等。

如果你进入房间后，拉了两次或以上杆且从来没中奖，离开房间时，老虎机会送给你一听可乐或一个鸡腿（自选）。可乐能回复4生命并在下一场战斗开始时为你额外恢复1魏启。鸡腿能恢复9生命并增加1你最大生命值。

大奖类型包含：全状态恢复、能开出的所有卡都齐平甚至超越你灵脉等级的卡包、平时无法获取的6选1的任意系高级卡包、免费指定卡牌升级、随机多次卡牌升级、高级灰色卡（通用卡）卡包、三选一A级遗物、S级遗物、金币堆（200-400不等）、特殊物品等。老虎机不能出S级卡包，只能出少量S级遗物。

老虎机和银行机成对出现，你可以在银行机上存储金币，并在下一次遇到它时提款领取收益，或继续存放从而享受越来越高的利率。你也可以从银行机超额取钱，获取金币，代价是你必须进行一次老虎机恶魔roll，roll结果为三个不同的Debuff，你必须选取一个在下一场或几场战斗将承受它。

在故事模式中，roll的第5、11次小奖为瑞米的苹果。获得这两个苹果后，roll的第2次大奖必然也是一个苹果“金苹果”。

### 老虎机价值兑换表

S类遗物/卡：老虎机无法吞噬，它会嚼一嚼之后吐出来，太难吃了。

A类遗物：60-70金随机。

B类遗物：40-50金随机。

C类遗物：20-30金随机。

A类卡：20-30金随机。

B类卡：10-20金随机。

C类卡：3-10金随机。

D类卡：0-5金随机。

诅咒卡：老虎机咀嚼后感到满意，你下次roll免费。

### 银行机

来 _借_ 点什么吧！

你可以在银行机存款，每过一层，连击数+1。利率每层结算，和连击数有关。

2连击或以下：5金每层产1金。
3连击：9金每层产2金。
4连击：4金每层产1金。
5连击或以上：7金每层产2金。

任何取款都会打断连击，从0在此开始计算。任何存款会让连击下跌到至多2。死亡会导致银行机存款清空。

如果你通过了一次黑色级恶魔roll并没死，此黑色级词条移出本场游戏（若是故事模式，则从此存档中永久移除），并且再次见到银行机时，它不会再让你从它那里超额取钱了。至少你第二次见到他才会允许你继续超额取钱。

在故事模式中，通过4个黑色级恶魔roll后，银行机会让你想办法跨轮回存满900金，从而“每次从一楼开始游玩时，第一次遇见它便能获得50金佣金”，并会给予你一个苹果以表诚意（瑞米被苹果勾引后就会不断敦促你存钱）。完成后，在2次游玩并成功收到69佣金（第一次收50，第二次银行机以短期投资效益不好为由只给了19金）后，银行机跑路了，你在老虎机楼层再也找不到银行机了。

在肉鸽模式中，银行机会一直认真工作，不会有存900金以及跑路的小插曲。玩家没有和老虎机以及银行机的对话。初见时，其机能介绍由背景音完成。

### 恶魔roll

Debuff列表

* 黑色级（90金）：
    重伤：损失65%当前生命值，但生命上限永远增3。
    忘却：随机焚毁你牌库中2张卡牌（不会焚S级卡），然后你可选一张卡焚毁。
    浑浑噩噩：下一张战斗中，初始抽牌数-1，回合开始时抽牌数-1，但你可立马选一张卡升级。
    脆弱：下一场战斗中，战斗开始时，脆弱5，但你立刻恢复5生命。
    无力：下一场战斗中，战斗开始时，虚弱7，但你攻击永远+1。
    绝望：下一场战斗中，你于第4回合结束时死亡，下次遇到老虎机会送你一次免费roll。
    失明：下一场战斗中，你无法看见敌人意图。
    残废：下一场战斗中，战斗开始时，伤残5，但你防御永远+1。
    无梦：下一场战斗中，魏启不再自动回复，但你魏启上限永远+1。

* 红色级（40金）：
    受伤：损失20%当前生命值。
    忘记：随机焚毁你牌库中1张卡牌，不会焚S级卡。
    昏头：下三张战斗中，前2回合开始时抽牌数-1。
    脆性：下三场战斗中，战斗开始时，脆弱1。
    乏力：下三场战斗中，战斗开始时，虚弱1。
    落魄：下三场战斗中，从第4回合开始，每回合结束时受到7伤害。
    残疾：下三场战斗中，战斗开始时，伤残1。
    噩梦：下三场战斗中，前2回合，魏启不会自动回复。

* 黄色级（15金）：
    擦伤：损失10%当前生命值。
    犯困：随机降级你牌库中1张卡牌。
    晕乏：下一张战斗中，前2回合开始时抽牌数-1。
    软化：下一场战斗中，战斗开始时，脆弱1。
    劳累：下一场战斗中，战斗开始时，虚弱1。
    失望：下一场战斗中，从第4回合开始，每回合结束时受到7伤害。
    出血：下一场战斗中，战斗开始时，伤残1。
    失眠：下一场战斗中，前2回合，魏启不会自动回复。
