# 战斗规则总则（battle.md）

> 本文档是战斗玩法的形式化设计规则（策划）：定义战斗的流程结构、回合状态机、胜负条件、单位与资源规则、牌区与出牌规则、结算时序公理与数值基准。
> 规则条目按章节编号（如 **B3**、**T7**、**F2**），供设计讨论与后续内容（技能/敌人/遗物提案）引用。
> 与实现代码的对应关系一般不在本文范围内；未定项与构思见 `battle_thoughs.md`。


## 1. 术语与定义

### 顶级术语

| 术语 | 定义 |
|---|---|
| **战斗** | 一场敌我对抗的完整过程：战前准备 → 回合循环 → 战后结算 |
| **回合（Turn）** | 回合循环的基本单元，严格交替：玩家回合 → 敌方回合 → … |
| **阵营（Side）** | 我方（玩家本体 + 盟友）与敌方；盟友属我方阵营 |
| **主角** | 玩家操控的主要角色，在游戏中为骑士。 |
| **单位（Unit）** | 战斗中的实体：主角本体、盟友、敌人；持有生命/护盾/属性/效果 |
| **卡牌（Card）** | 主角可打出的技能载体；有费用、等阶、系列、关键词等字段，可被发动 |
| **区域（Zone）** | 卡牌所在的位置：手牌 / 牌库 / 弃牌堆 / 坟墓 |
| **施放资源** | 魏启、行动点（AP）、护盾、金币 |
| **效果（Effect）** | 挂在单位上的状态（可叠层），按自身规则持续生效 |
| **结算** | 一次游戏规则的执行过程（伤害、抽牌、赋盾……），其结果可引发联动 |
| **联动（Trigger）** | 一个概念，由某次结算中途引发的额外结算效果（如"受击时格挡-1"），在实现中一般通过在结算树上监听并插入原语完成 |
| **修正（Modifier）** | 结算前对数值的改写（增减、倍率、剪裁） |

**基础约定（效果作用域）**：卡牌描述中的增益、进阶、转化等效果，**默认作用域为「一场战斗」**——除非卡面明写「永久」（跨战斗持续），否则战斗结束后一切回到牌组构筑时的状态。例：斩的局内进阶、威力加成、消耗移除，均不跨战斗。


## 2. 战斗顶层流程

```
┌─────────┐   ┌───────────────────────────┐   ┌─────────┐
│ 战前准备 │ → │         回合循环           │ → │ 战后结算 │
└─────────┘   │  玩家回合 ⇄ 敌方回合 交替   │   └─────────┘
              └───────────────────────────┘
```

**B1（战前准备）** 按下列次序执行，然后进入回合循环：

1. 玩家战斗字段初始化：护盾归零、效果清空、AP 回满、**魏启置为上限一半（下取整）**（生命为跨战斗持久量，不重置）；
2. 玩家构筑牌组洗混后成为本场牌库；
3. 常驻来源（能力、已装备遗物）的战斗开始效果生效；
4. 敌方展示**初始意图**；
5. 抽起手牌 **4** 张。

**B2（回合循环）** 玩家回合与敌方回合严格交替，循环无上限；胜负判定成立是唯一出口（见 §4）。

**B3（战后结算）** 战斗结束：清空本场全部持续来源（效果/咏唱/常驻触发），落定战斗结果，交回 run 层（奖励 / 幕间）。

## 3. 回合结构

### 3.1 玩家回合（七阶段）

| # | 阶段 | 内容 |
|---|---|---|
| P1 | 主角回合开始 | ① 回合数 +1；② 主角护盾清零；③ AP 回满，魏启回1；④ 结算"回合开始"类触发  |
| P2 | 冷却推进 | 手牌与牌库中的卡推进充能冷却（见 **C5**） |
| P3 | 主角抽牌 | （**例外**：本场第一个玩家回合不抽牌——起手牌已由战前发放） |
| P4 | 玩家操作 | 玩家操作主角自由阶段：出牌 / 换牌，任意次、任意序，直到玩家宣告**结束回合** |
| P5 | 主角咏唱卡触发 | 主角的激活的咏唱卡触发效果。（注，部分咏唱卡没有触发效果，而只提供激活时的被动效果）。 | 
| P6 | 主角回合结束| 如题，此时才进行主角回合结束的结算。 |
| P7 | 盟友行动 | 我方存活盟友按站位序依次行动 |
| P8 | 回合结束 | 结算"回合结束"类触发（如滞气层数 -1），清扫"本回合内"限定的规则 |

### 3.2 敌方回合（三阶段）

| # | 阶段 | 内容 |
|---|---|---|
| E1 | 回合开始 | **敌方全体护盾清零**；结算敌方阵营的"回合开始"触发 |
| E2 | 敌人行动 | 存活敌人按站位序（数组序）依次执行其意图 |
| E3 | 回合结束 | 每个存活敌人预算并展示**下回合意图**；结算"回合结束"触发 |

**T1（意图规则）** 敌人意图在行动前始终可见（战前展示初始意图，之后每敌方回合 E3 更新），行动时按当前意图执行。

**T1a（意图分类）** 意图只区分五种基础意图，前四种可**两两组合**概括几乎所有行动：
① **攻击**——显示「次数 × 数字」（次数为 1 时省略，只显数字）；② **防御**；③ **增强**（自我或友军增益：上盾、再生、荆棘、蓄势、自愈等）；④ **削弱**（赋予对方减益：燃烧、虚弱、滞气等）；⑤ **未知**（不公开意图的敌人）。除攻击附带数字文本外，其余意图**仅以图标**展示，不写详细信息。

**T2（护盾存续通则）** 护盾不自燃衰减，在**获得方自己的回合开始时清零**——护盾只保护"获得之后的整个对方回合"。由此：先取得护盾的一方天然占优，护盾 timing 是核心博弈点。

**T3（手牌上限·加权口径）** 手牌有容量上限（初始 7，能力可改）：激活的咏唱卡按其咏唱值计多张（咏唱N = 计 N 张），其余卡恒计 1；加权手牌数达上限后抽牌落空（卡留牌库原位）。牌库抽空时抽牌落空，不判负。

## 4. 胜负条件

**V1（失败）** 玩家本体生命 ≤ 0 → 立即失败。
**V2（胜利）** 敌方存活单位数为 0 → 立即胜利。
**V3** 盟友死亡**不构成**失败（仅失去其行动与效果）。
**V4（即时性）** 判定在任何结算完成后即时检查；判定成立瞬间战斗结束，不再有后续回合/阶段。
**V5（死亡单位）** 生命 ≤ 0 即视为死亡：不参与行动序、不可被指定为目标；"不灭"类规则可将死亡线压至更低（见 **F4** 地板）。

## 5. 单位与状态

### 5.1 单位属性

| 属性 | 含义 | 备注 |
|---|---|---|
| 生命 HP | ≤ 0 即死亡（受地板规则保护，见 F4） | 玩家的生命**跨战斗持久** |
| 护盾 | 战斗内临时缓冲，吸收伤害（见 F2） | 获得方回合开始清零，无上限 |
| 攻击 / 防御 / 法术 | 面板属性；参与算式（见 F1） | 实际取值 = 基础值 + 效果提供的修正总和 |
| 效果列表 | 挂载的状态（见 §10） | 战斗开始时玩家清空 |

**U1（面板轨）** 任何算式读取属性时，一律读"基础值 + 当前所有修正"——同一口径，无第二来源。

### 5.2 单位寿命

| 单位 | 寿命 | 说明 |
|---|---|---|
| 玩家本体 | run 级（跨战斗） | 生命、牌组、金币、能力、灵脉等级持久（魏启为战斗内资源，见 §6） |
| 盟友（瑞米等） | 战斗级 | 我方阵营；在玩家回合 P7 行动 |
| 敌人 | 战斗级 | 站位序 = 行动序 |

### 5.3 目标规则

- **G1** 玩家指定目标：出牌时指定，**结算时校验存活**——点击到结算之间目标死亡则目标落空，改走该卡的默认目标规则。
- **G2** 默认目标：需指定敌人的卡默认指向**最前方（首位）存活敌人**；全场无存活敌人时结算退化为面板值（收尾用）。

## 6. 资源体系

| 资源 | 寿命 | 恢复规则 | 上限规则 |
|---|---|---|---|
| **生命 HP** | run 级持久（跨战斗） | 营地休整 35% 最大生命（`CAMP_PLACEHOLDER.restHealRatio`）、事件/卡牌治疗 | 初始 **50**（全局常量 `PLAYER_BASE_HP`，`core/state/player.js`——平衡调整只动这一处，代码与测试统一引用） |
| **魏启 MP** | 战斗内，入战时MP为上限一半（下取整） | 回合开始时恢复1 | 上限 3（初始），**每次进阶 +1**（总上限 = 3 + 总进阶次数，封顶 +6）；获取受上限截断 |
| **行动点 AP** | 战斗内 | 每玩家回合 P1 **回满** | 上限 3（初始）；获取不受上限截断 |
| **护盾** | 战斗内 | 无自然衰减；获得方回合开始清零（T2） | 无上限 |
| **金币** | run 级持久 | 战后奖励 | — |

**R1（费用规则）** 打出卡牌需同时支付其魏启与 AP 费用；**任一不足则不可打出**（存在"费用豁免"类能力时除外）。
**R2（费用可修正）** 费用在支付时点可被修正（减免/增加）——费用管线与数值管线同构。
**R3（换牌）** 玩家自由阶段内可**换牌**：将 1 张手牌置回牌库底（FIFO，见 **Z2**）、抽 1 张。费用 = 已换次数（首次 0，逐次 +1），可被能力封顶。换牌抽牌**不受**"回合开始抽牌数修正"影响。

## 7. 牌组与区域

### 7.1 区域

| 区域 | 说明 |
|---|---|
| 手牌 | 有序；卡位有语义（"两侧"/"最右"等位置敏感机制） |
| 牌库 | 有序；**约定牌库顶 = 下一次抽的牌**；部分机制可"从牌库底抽" |
| 弃牌堆 | 打出/弃置的卡去处 |
| 坟墓 | **消耗**卡以及被焚毁的卡的去处。这些卡进入坟墓前会直接被移出战斗，不会返回其他区域。 |

**Z1** 任何时刻一张卡恰在一个区域；区域迁移是唯一事实来源，位置派生自查。
**Z2（无弃牌堆·无重洗）** 牌库即唯一循环区：打出、换牌、解除咏唱等原因离手的非消耗卡一律置回牌库底，抽牌自顶取用——先进先出，不存在"弃牌堆"，也不发生洗混重洗。

### 7.2 卡牌字段速览

费用（魏启/AP）· 等阶（D→C→B→A，S/Z 阶梯外）· 系列/灵脉 · 关键词（**消耗**、**锚定**等）· 卡种（普通/咏唱；咏唱卡另带**咏唱值 N**）· 充能。

**费用缺省约定**：设计稿中未写费用的卡视为免费（0 费用）打出。

### 7.3 卡牌动态

**移动** 卡牌可以在四个个区域中移动。特别的，当卡牌因为手牌满无法移动到手牌区域时，卡牌会尝试移动进牌库。若仍失败，卡牌焚毁。

**转化** 卡牌可**原地转化为另一张卡**：身份（同名卡序位）、所在区域、位置、威力强化全部延续——与"焚毁再造"是两种语言。局外升阶（D→C→…）同用转化语言。

**焚毁** 卡牌焚毁即为卡牌离场。焚毁的卡牌进入坟墓（坟墓）。

**打出** 玩家打出一张手牌，消耗资源，将其发动，卡牌离手的过程。

**发动** 卡牌效果生效的过程。注意，发动和打出是两个概念，打出一般包含卡牌的发动过程。

## 8. 打出流程

**C1（可打出条件）** 同时满足：① 费用足够（或有豁免）；② 充能未耗尽；③ 卡牌本身特殊可打出条件判定通过。
**C2（打出的结算次序）** 打出一张卡按下列次序结算：

```
① 展示宣告 → ② 支付费用（可被修正）+ 消耗一格充能（耗尽则启动冷却）
→ ③ 发动卡牌，执行卡牌效果
→ ④ 离手去向：消耗卡 → 坟墓；其余 → 弃牌堆
```

**C3（发动的结算）** 发动卡牌效果，其结算由后端结算器完成，过程非常复杂（可能嵌套其它卡牌的打出等），并可能需要用户异步输入。
**C4（充能与冷却）**

- 每次打出消耗 1 格充能；
- 充能耗尽且该卡带冷却时进入冷却，**每玩家回合 P2 推进 1**；
- 冷却只在**手牌与牌库**推进（弃牌堆中不推进）；个别卡可声明更窄的推进区（如"仅在牌库中冷却"）；
- 冷却归零回充 1 格；未满充能则继续下一段冷却。

**C5（咏唱）**

- 咏唱卡有激活和未激活两种状态，战斗开始时所有咏唱卡未激活。
- 【咏唱N】表示咏唱卡激活后，占据N手牌容量。激活的咏唱卡会提供其被动，或者在咏唱卡触发阶段提供特别效果。
- 未激活咏唱卡打出后变为激活状态并回到手牌，提供持续性效果，占据额外手牌容量。
- 打出激活的咏唱卡会让其进入牌堆或焚毁（消耗卡）。
- 任何时候，咏唱卡离开手牌时都推出激活状态。
- 咏唱卡激活后若导致手牌超出上限，则此咏唱卡无法打出

## 9. 攻击与治疗结算（公式与时序）

### 9.1 攻击结算（固定管线）

对一次攻击 **D**：

```
第一步（修正）    D' = 对 D 依序应用全部修正（格挡减半、易伤加深、闪避归零……）
第二步（防御）    d₁ = max(D' − 目标防御, 0)
第三步（护盾）    吸收量 a = min(护盾值, d₁)；护盾 −= a；d₂ = d₁ − a
第四步（受伤）    生命 = max(生命 − d₂, 地板值)
```

**F1** 攻击类卡伤害 = 基数 + 攻击面板 + 威力（面板读 U1 口径）。
**F2（固定伤害）** 固定伤害是一种伤害类型，固定伤害跳过第一步与第二步。
**F3（格挡层数在修正步消耗）** 格挡在第一步把伤害减半（下取整）并 -1 层——因此格挡先于防御/护盾生效。
**F4（地板）** 存在"生命不会低于 X"的地板规则（不灭类，默认 X=0）。
**F5（治疗）** 治疗不超过生命上限；护盾获取无上限。

### 9.2 时序公理

- **A1（结算原子，联动在后）** 一次结算先完整走完管线，由它引发的联动在其后结算（"受击反击"不会插进伤害公式中间）。
- **A2（修正有严格次序）** 同一次结算的多个修正按**优先级从高到低**依序应用；不存在"固定乘区"式的左右交换。
- **A3（触发挂点明确）** 一切联动挂在明确的时点上（回合开始/结束、受击、打出、抽牌……），时点未到不触发。
- **A4（被取消的结算无联动）** 结算被取消（如被闪避）时不引发任何后续联动。
- **A5（预估与结算同源）** 面向玩家展示的预估数字（"应用后"卡面）走与真实结算完全相同的修正管线——所见即所算。

## 10. 效果体系

**X1（通用规则）** 效果挂在单位上、可叠层；获得时开始生效，层数扣尽自动移除。效果的具体行为由各自定义描述，结算代码不特判任何效果名。

## 11. 数值基准（现行）

| 项 | 值 |
|---|---|
| 起手抽牌量 | 4 |
| 初始手牌容量 | 7 |
| 每回合抽牌 | 2（首回合不抽） |
| 初始 AP | 3 / 每回合回满 |
| 初始手牌上限 | 7 |
| 初始魏启 | 初始上限 3；**每次进阶 +1**（含每个灵脉的首次进阶；总进阶封顶 6 → 上限 9）；入战半满（下取整），每回合开始 +1 |
| 初始卡组 | 拳×3 + 盾×3 + 抱头×1 + 肾上腺素×1 + 情况不对×1 + 斩×1（共 10 张） |
| 换牌费用 | 首次 0，逐次 +1（可被能力封顶） |
