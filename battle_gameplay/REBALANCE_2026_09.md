## 背景：问题清单

1. **非体修删卡机会不够**——全员体修开局，转体系的玩家背着一整副死重；删卡只有 Boss×4 + 部分事件。
2. **升级没存在感**——训练房单卡升一阶 vs 开包 lv2 即 5%A / lv3 起 3%S，欧皇一发入魂，升级像低保。
3. **魏启痛点**——用户自述有痛点，具体待补充（见「待讨论队列」）。
4. **敌人爬坡慢**——人类 7/8 层起爆杀。分析：难度预算几乎全在血（HP ×(1+0.4(d−2))），
   攻击只 +floor((d−2)/2) 几乎不涨；输出达标即无损速杀，不达标被磨死——**威胁与血牛绑在同一根轴上**。
5. **弃牌按钮过强**——阶梯费（首 0 逐次 +1）即可任选弃任意张，外科手术式弃牌让诅咒/状态卡/完美卡的限制失效。

## 已确认的判据

- **回蓝是策略检查点，不是稀缺约束**（2026-09-21 用户定）：「随便抓两个回蓝卡就能保证蓝用不完」。
  agent 局缺蓝 = build 策略不及格，**不为此调系统补给**。

## 决策记录

### D1 基础数值：AP 3 / 手牌 5 / 体修补偿（方向已定，细节待钉）

- `PLAYER_BASE_AP` 4 → 3；`maxHandSize` 默认 6 → 5。
- **体修基础能力改为「AP 上限 +1」**（体修实质维持 4 AP）。
- 理由：法师每回合 1~2 张高费牌，4 AP 永不构成约束；3 AP 让 AP 对所有体系成立，
  并形成分工轴——**体修吃 AP，法师吃魏启**。
- 待钉：
  - 原体修基础能力 = 起始卡组白送 1 张肾上腺素；肾上腺素在新时代的去留（保留为普通起始卡 / 移除）。
  - 影响面复验：咏唱手牌权重压力、雪狼震慑塞牌（塞 2/5 更疼）、「抽满手牌」类卡、
    弃牌阶梯费在 3 AP 下的体感、筹算灵/挡拆等按出牌量联动的件（间接受削，可接受）。

### D2 开局路线选择，体系专属起始牌组（方向已定，细节待钉）

- **开局选体系（杀戮尖塔式选角）**：各体系有专属起始牌组 + 体系基础能力开局即授予。
- 动机：现行「首进阶送 2 卡 + 体系能力 + 种子包九选三」本质是给「全员体修开局 → 转型慢」打的补丁；
  路线选择直接消除病因，同时**大幅吸收痛点 1**（不再有整副异体系死重要删）。
- 起始牌组构成：**体系核心 D 卡 + 通用 拳/盾 填充**（拳/盾定为全体系通用卡，2026-09-21 用户定；
  火系纯低阶卡撑 8~9 张会难受，拳盾填充解决）。
- 待钉：
  a. ~~选火路线 = 火灵脉开局即 1 级？~~ → **已定（2026-09-21）：路线选择即授予 leino 1**
     （起始状态，不占 6 次进阶额度——按自然理解记录，若有出入再改）。
  b. ~~体修路线的对价~~ → **已定（2026-09-21）：体修啥都不拿**——这是走体修的代价；
     相应的体修卡组强度上限非常高（会玩的前提下）。
  c. 种子包的新定位：改为「局中点燃第二体系 0→1 时的骨架包」保留（首体系不再需要它救火）。
  d. 木/空未实装——路线 UI 只显示已实装体系。
  e. 「体修基础能力」目前只是起始卡组构成，不是注册表能力；路线制下各体系基础能力要落成真实对象。

### D3 弃牌按钮改制：一键弃全部手牌（方向已定，细节待钉）

- 现状（`battle.js` 的 `playerDumpCards`）：付阶梯费 → **任选**弃任意张回牌库底。
- 新制：点击 = **弃掉手中所有卡**（回牌库底口径不变）。诅咒/状态卡的卡手设计重新长牙。
- **阶梯费保留**（首 0 逐次 +1，2026-09-21 用户定）。
- 待钉：
  - 误触防护（一键清空手牌的确认或手势成本）。
  - 复验联动：后手卡（空手条件）、震慑等塞牌、咏唱点亮卡被弃的熄灭路径。

### D4 等阶与升级重做：升级降级为添头，抓卡成为强度主轴（方向已定，细节待钉）

- **移除 D 阶**；清出一批无意义 C 卡；**强机制卡只从 B/A 起步，甚至只从 A 起步**。
- **灵脉等级不再影响卡包概率**（PACK_TIER_TABLE / tierCapOfLevel / MIN_TIER_LEVEL 整套脱钩）。
- **拉近同卡相邻等阶的差距**——升级收益刻意做小。
- 训练房新制：**升 2 张 C→B，或升 1 张 B→A**（替代原单卡升一阶；原「删一张或升」的二选一雏形中
  「随机升 2」半个想法已当场收回）。
- **营地不再能升级卡**，只保留回血 / 找回瑞米等。
- **拳/盾（通用填充卡）不走体修路线无法升级**。
- 设计哲学（用户定，agent 赞同）：**等阶 = 机制复杂度/构筑围绕度，≠ 强度**；某些 C 比 A 强完全可以接受
  （杀戮尖塔同构：稀有度表达专精而非数值）。卡牌固有力差距 > 等阶差距是预期状态。
- 动机：① 升级收益过高导致玩家追「核心卡等级」而非整体提升；② 五等阶稀释卡池密度，
  强机制做不出 D 变体，同系列充斥着凑数变体。
- 待钉：
  a. ~~删卡的落点与密度~~ → **已定（2026-09-21）：删卡主渠道 = 老虎机粉碎**——连抽阶梯从
     +6/次 降为 **+3/次**（7 次门槛从累计 161 金降到 98 金），粉碎换金同时承担瘦身职能；
     Boss 奖励删卡与事件删卡保留。
  b. **灵脉等级的剩余职能清单**：能力授予 / 蓝上限 +1 / 全恢复之外还剩什么？深入卡的精英能力门禁保留吗？
  c. ~~S 阶投放~~ → **已定（2026-09-21）：S 不在卡包内自然出现**（回归 RUN_DESIGN 原意，只走事件）。
  d. ~~A 卡开局即可出现是预期吗~~ → **已定（2026-09-21）：A 直出只挂在精英/Boss 战后奖励**；
     普通战后卡包上限 B，其余只能靠训练场升级。等阶门禁从「等级制」改为「来源制」。
  e. 升级门禁是否同步取消：火路线玩家抽到体修卡能升吗（拳/盾已是特例）？
  f. 训练房保底：牌组里没有 C（或没有 B）时训练选项落空——给什么兜底（原规则是改为抓牌）？
  g. 训练营消费档（原「花钱→卡+升级 ×3」）在 D 移除后的形态。
  h. 大扫除清单：现 D 卡哪些升 C、哪些删；现 C 卡哪些移除——逐卡过，这是主要内容工作量。
     **大扫除时同步重做各等阶数值基准**（用户定：等阶扁平化后逐卡重新标定，属后续专项）。
     进度：火系设计稿已由用户改完（2026-09-21）；**体修设计稿已按同口径改完**（同日 agent 改，
     待用户验收）；通用卡 / 木 / 空待做。

### D5 老虎机加强（2026-09-21 用户定）

- **每次进老虎机房免费赠送 2 次抽奖**（之后进入付费连抽，阶梯 +3/次，见 D4-a）。
- **安慰奖收紧**：仅当**同一层内**累计拉杆 ≥4 次且**全程零获奖**时才触发（可乐/鸡腿二选一）。
  原触发条件为「拉过 ≥2 次且从未中奖」。
- 待钉：免费 2 抽是否计入 ① 粉碎计数（每 7 次一圈）、② 安慰奖的 4 次门槛、
  ③ 大小奖概率爬坡（小奖未中 +7%/大奖 +2%）——默认按「是」理解，待确认。
- 注意：与缺漏扫描 #4 叠加后，老虎机让利幅度 = 免费 2 抽 + 连抽降价，金币与奖励通胀更明显。
