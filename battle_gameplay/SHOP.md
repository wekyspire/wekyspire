# 商店
游戏中，玩家在一定层数的休息阶段会遇到商店，此处玩家可以消耗金币购买卡包、遗物、瑞米最爱的苹果、特殊商品等。

商店由两个性质完全不同的渠道组成：一台瑞米维护的自动售货机（常规、便宜、随机性低），以及35层的古尔帕斯把原本的战斗层改造而成的店铺（昂贵、稀有、需要特殊物品兑换、几乎全是旧魏启大陆的东西）。


## 一、瑞米维护的自动售货机

形态：一台嗡嗡作响的自动售货机，玻璃柜里码着几件货。全塔的售货机都由维护机械装填，瑞米也常来帮忙——它修过拉杆、转轮和里面的小灯，和它们关系可好了。

定位：常规补给。给金币一个稳定的日常出口，并用确定性去平衡卡包三选一的随机性。想要什么，这里是能直接买到的。

商品与价格（每次遇到刷新，货架 3~5 件）：

| 商品 | 价格（金） | 说明 |
| --- | --- | --- |
| 卡包（体修 / 已解锁灵脉） | 20–35 | 买到即开，仍是包内三选一；价随门禁上浮。通用包不单卖，只按原规则随机混入 |
| C 级遗物 | 25–35 | 便宜货，随手补一件 |
| B 级遗物 | 45–60 | 偶上架，是售货机的镇店之宝 |
| 恢复药剂 | 20 | 总是有且只有一件，恢复15%生命上限 |
| 苹果（瑞米最爱的苹果，仅故事模式，全流程中仅一件） | 199 | 偶尔能见到，可以喂给瑞米，提升等级与好感——售货机是它在维护，货架上摆它的心头好，理所当然 |


* 每次遇到限量，买光不补；下次遇到换新货。
* 商品按玩家灵脉等级的口径展开（与卡包、训练抓牌同一门禁），并按等阶加权，保证出现即有用。门禁达 B 以上时不下放 D 级废牌。

与瑞米的联动（仅故事模式）

* 瑞米在队：货架满、价格正常。
* 瑞米被打跑后结束游戏，下一次遇到商店时：冻结在上次轮回时立刻的状态中（可能缺少商品）。此时，瑞米会不好意思地解释“上次逃得太狼狈了，嘿嘿...忘记补货了...”
* 瑞米等级越高：货架位更多、偶有折扣。在瑞米等级4（4苹果）之后，即便上一次轮回在瑞米被打跑的情况下结束爬塔，瑞米仍能完成补货。首次触发时还有特别对话。

*出没：固定出现在 **4 / 8、15 / 19、25 / 29、36 / 40** 层的休息阶段（每章两次，避开训练层 4N-2、Boss 层 11N 与 Boss 前营地层）。它不占奖励房名额，与老虎机/营地/事件并存，是休息阶段的一个常驻货架。


## 二、古尔帕斯之店

形态：本该是一场战斗的某一层，没有敌人。战斗舞台被改成店铺：拉下来的卷帘门、一张工作台、几排货架，堆满旧大陆的物件。柜台后面坐着古尔帕斯——古佩·诗菲。

塔主把遗民分层安置，每层一间屋子；这一层原本分给她当守卫。她把守卫的位置改成了柜台——她不肯守，她要开店。塔楼程序对此不满，却在她自己的层里拿她没办法。（33 层看守者Boss暴毙、塔楼程序顶替呼应：这层是塔楼程序账面上的一处显性故障。）

古佩·诗菲的大多货物来自旧魏启大陆。她自己就是旧大陆的造物——2013 年被激活，一直活到 2257 年。塔里绝大多数东西都是道具，只有极少数是真的（10 层炉火房字条立的就是这个对照）；她柜台上摆的，是她亲手留下、亲手修过的真货。这也是它们贵得离谱的唯一理由。

| 商品 | 价格（金） | 说明 |
| --- | --- | --- |
| S 级遗物 | 190–390，以及一件她中意的A/B/C级遗物 | S 遗物目前只能从特定事件获得；她这儿能买到其中部分，且不会补货。大部分S级遗物被主角弄丢（携带遗物战败且不在瑞米手中）后会流入此处（即便主角并非从她这儿买来），并会去重。她不售卖主角已拥有的遗物。|
| 非槽位遗物（0 槽） | 100–200 | 拾起即生效、不占槽——攒够钱就是纯赚。会跨轮回补货。 |
| A 级遗物 | 100–200 | 总有几件 |
| A 级卡 | 90–120 | 直接能开出全A级卡的三选一卡包！ |
| B 级卡 | 30–50 | 同上，低价档 |
| 删卡服务 | 90–130 / 次，最多两张 | 借她的记忆修改能力，从牌库中彻底抹掉一张牌，在游戏中后期补足罕见的删卡途径，帮主角稳定最后的卡组推进至接近大成（只要你有钱） |

她收购遗物，只收 S / A 级。A 级给 90–120 金，S 级给 150–200 金。故事模式中，下次来如果主角想要，还能从她这儿买回去。卖不掉的货会一直留在货架上，下次来还是那个价。除非主角上一次暴时带着S/A级遗物让她捡了漏，她会给玩家打一次7折。

故事模式中，随游戏推进，她通过瑞米穿梭楼层的能力收集遗物的事情会渐渐揭示。她原来一直用一颗美味的苹果馋着瑞米让它心甘情愿地打工（这也是为何丢失的高级遗物都流入了她这儿）。

故事模式中，她的苹果是最后一果。在瑞米7果后，主角和瑞米日渐亲密，主角终于向她询价苹果。她给出了999金的报价。若某次轮回主角身上有超过500金，则主角可挑战她并（特殊boss战），胜利后，她会将苹果赠予主角。此后店内永久7折。

_或许只有你才能攀至塔顶，或许你已经攀爬了不止一次...谁知道呢。我等了太久了。_

商店固定出现在35层（避开训练层、Boss 层与 Boss 前营地层）。到这一层没有战斗，她店里也不设售货机，

故事模式中，她识得旧大陆的人与物，也精于记忆与精神。因此她初见骑士时候有短暂的的熟悉感。“我见过你吗？”这类问题只能换回骑士的沉默。瑞米和她很是熟络，这也是魏启尖塔多年来无人造访后她唯一能闲聊的对象。

故事模式中，部分遗物在此处第一次回收/买走时会触发特殊对话，集中在魏启大陆相关强力遗物上。

阿瓦凡无法在此买卖。尝试售卖阿瓦凡会被阿瓦凡拒绝。携带阿瓦凡死亡后，下次来到此楼层时，主角会遇见等待的阿瓦凡，并能在此处免费领取阿瓦凡。若阿瓦凡认瑞米为主，则会一直随瑞米出现和消失，不会在此出现。

肉鸽模式中，店主消失不见，这里没有任何对话。主角想要购买货架上的商品或删卡服务仍得付费，价格和机制相同且不打折z。主角死亡后遗物不会流入此处。此处的遗物为随机刷新机制。肉鸽模式内此处没有“跨轮回连续”的特性。
